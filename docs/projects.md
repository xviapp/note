# 项目与文件引用

选择「新建 → 更多类型 → 项目」，应用创建项目目录，以及其中的 `todo`、`issue`、`note` 三个子目录。项目页自动汇总这些目录及更深子目录中的 Markdown 文件，分类标签分别使用待办清单、问题提示和笔记图标。其他格式的文件仍可保存在目录中，但不进入项目列表。

在各分类中用「新建待办」「新建问题」「新建笔记」添加独立的 Markdown 条目。条目底部可直接补充讨论、记录进展或追加笔记，标题可选，支持文字及多张照片；照片作为正文图片和附件写回原文件。回车换行，Ctrl/Cmd+Enter 保存。输入和已上传照片暂存在本设备，加密条目的草稿同样加密；上传和提交需要联网。失败保留输入和照片，版本冲突后重试会接在最新正文后。

问题和待办的追加写入「## 讨论」或「## 进展」小节，每条以「### 2026-10-07 14:05 · 标题」开头；没有小节时自动创建，未填标题时只有时间。笔记追加不带时间，可选标题作为二级标题。阅读时讨论显示为卡片，进展显示为时间线，记录不进入「本篇目录」；源码仍是普通 Markdown。旧的引用块时间标记也能识别，无需迁移。

条目页可在「⋯」菜单中编辑全文、查看历史、翻译、批注和已有下级笔记；新条目在项目概览创建。

待办和问题的状态可在标题右侧或项目概览切换。状态更新文首资料，并在讨论或进展小节记录时间和变化，生成历史版本；相同状态不会重复记录。在条目页完成待办或关闭问题时可附上结论，项目概览中切换不询问结论。已完成或已关闭后仍可追加、重新切换状态；追加不会自动改变状态。

## 标题与状态

文件使用文首资料记录标题和状态，例如：

```markdown
---
title: '支持文件夹引用'
status: todo
---

这里写具体说明、实施方案和检查清单。
```

`title` 和 `status` 使用单行文字，可以加英文单引号或双引号。其他文首字段会原样保留。阅读时隐藏这些资料，编辑源码时可以查看和修改。

| 目录    | 状态                      | 显示文字               |
| ------- | ------------------------- | ---------------------- |
| `todo`  | `todo` / `doing` / `done` | 待办 / 进行中 / 已完成 |
| `issue` | `open` / `closed`         | 待处理 / 已关闭        |
| `note`  | 不要求状态                | 笔记                   |

缺少有效 `title` 时，项目页取正文中第一个一级标题，再回退到文件名称；代码块中的标题不参与提取。缺少状态显示「未设置」，不支持的状态显示「待调整」并保留原文。状态重复、使用多行资料或文首分隔线不完整时，需要先编辑原文件，再从项目页修改状态。

分类由项目下第一层目录名称决定，忽略大小写和名称两侧的空格。把文件或包含它的子目录在 `todo`、`issue`、`note` 之间移动后，分类随之更新，正文中的状态保留。例如，已完成的待办移入 `issue` 后，需要选择该分类支持的状态。移出这三个目录或进入回收站后，不再出现在项目列表；恢复后自动重新收录。

项目页汇总待办进度和未关闭问题数，可筛选未完成内容。进行中条目排在最前，已完成和已关闭排在最后。「打开目录」可查看原文件，「⋯ → 刷新项目」重新读取汇总。标题和状态以已保存正文为准，未保存草稿不参与汇总；新建和保存时同步更新摘要，旧文件或恢复的备份首次打开时分批整理。项目概览需要联网。

## 文件与文件夹引用

选择「新建 → 更多类型 → 文件／文件夹引用」，选取原内容并填写可选名称。引用是笔记树中的独立入口，打开后可以进入原文件或原目录；内容保留在原位置，不会复制。引用本身可以重命名、移动、收藏或删除。向引用添加内容时，需要先打开原目录。

把文件引用放在三个分类目录中，该 Markdown 原文件就会进入对应项目列表；文件夹引用会收录目标目录中的全部 Markdown 文件及下级引用。也可以将项目下第一层的文件夹引用命名为 `todo`、`issue` 或 `note`，作为该分类的索引入口。同一分类中，同一个原文件只出现一次；循环引用不会造成重复或无限遍历。

从项目概览进入引用条目时，使用该项目对应的分类页面，地址保留项目和分类信息，刷新或返回后仍保持该视图；独立打开原文件时按原位置显示。从项目页面追加内容或修改状态都会写回原文件，其他引用该文件的项目刷新后也会看到新内容和状态。删除引用保留原内容；原内容在回收站中或已永久删除时，项目页提示引用不可用。整库备份包含项目和引用关系，恢复时会映射到新文件，重新生成项目摘要。
