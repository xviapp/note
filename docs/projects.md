# 项目与文件引用

选择「新建 → 项目」，应用创建项目目录，以及其中的 `todo`、`issue`、`note` 三个子目录。项目页自动汇总这些目录及更深子目录中的 Markdown 文件，分别使用待办清单、问题提示和笔记图标。其他格式的文件仍可保存在目录中，但不进入项目列表。

项目页可新建待办、问题和笔记，填写标题和可选说明；每一条都会保存为所属目录中的独立 Markdown 笔记。点击条目打开原文件，可继续编辑正文、添加附件或查看版本历史。项目列表的状态修改也写回原文件并生成历史版本；如果文件已被其他页面修改，会提示刷新，保留其他页面的新内容。

## 标题与状态

文件使用文首资料记录标题和状态，例如：

```markdown
---
title: '支持文件夹引用'
status: todo
---

这里写具体说明、实施方案和检查清单。
```

`title` 和 `status` 使用单行文字，可以加英文单引号或双引号。其他文首字段会原样保留。阅读时隐藏这些资料，编辑源码时可以查看和修改。

| 目录    | 状态                      | 显示文字               |
| ------- | ------------------------- | ---------------------- |
| `todo`  | `todo` / `doing` / `done` | 待办 / 进行中 / 已完成 |
| `issue` | `open` / `closed`         | 待处理 / 已关闭        |
| `note`  | 不要求状态                | 笔记                   |

缺少有效 `title` 时，项目页取正文中第一个一级标题，再回退到文件名称；代码块中的标题不参与提取。缺少状态显示「未设置」，不支持的状态显示「待调整」并保留原文。状态重复、使用多行资料或文首分隔线不完整时，需要先编辑原文件，再从项目页修改状态。

分类由项目下第一层目录名称决定，忽略大小写和名称两侧的空格。把文件或包含它的子目录在 `todo`、`issue`、`note` 之间移动后，分类随之更新，正文中的状态保留。例如，已完成的待办移入 `issue` 后，需要选择该分类支持的状态。移出这三个目录或进入回收站后，不再出现在项目列表；恢复后自动重新收录。

项目页显示待办完成进度，并可筛选未完成待办或未关闭问题。标题和状态以已保存的正文为准，未保存的编辑草稿不参与汇总。新建和保存文件会同步更新摘要；旧文件或恢复的备份首次打开时，项目页会分批读取并自动完成整理。项目概览需要联网。

## 文件与文件夹引用

选择「新建 → 文件／文件夹引用」，选取原内容并填写可选名称。引用是笔记树中的独立入口，打开后可以进入原文件或原目录；内容保留在原位置，不会复制。引用本身可以重命名、移动、收藏或删除。向引用添加内容时，需要先打开原目录。

把文件引用放在三个分类目录中，该 Markdown 原文件就会进入对应项目列表；文件夹引用会收录目标目录中的全部 Markdown 文件及下级引用。也可以将项目下第一层的文件夹引用命名为 `todo`、`issue` 或 `note`，作为该分类的索引入口。同一分类中，同一个原文件只出现一次；循环引用不会造成重复或无限遍历。

在项目页修改引用条目的状态会修改原文件，其他引用该文件的项目刷新后也会看到新状态。删除引用保留原内容；原内容在回收站中或已永久删除时，项目页提示引用不可用。整库备份包含项目和引用关系，恢复时会映射到新文件，重新生成项目摘要。
