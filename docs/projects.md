# 项目与文件引用

新建项目后，目录中会有 `todo`、`issue`、`note` 三个子目录。项目页汇总其中及下级目录里的 Markdown，其他格式只保存在目录中。

在分类中创建待办、问题或笔记。项目概览需要联网，按已保存的正文汇总；进行中排在前面，完成或关闭的排在最后，可筛选未完成条目。

## 追加与状态

条目底部可追加文字和多张照片，Ctrl/Cmd+Enter 保存。照片后台上传，未传完时可先保存。草稿和照片保存在本机，加密条目的草稿也加密；失败后可重试，版本冲突时追加到最新正文。

问题的追加写入「## 讨论」，待办写入「## 进展」，每条带时间和可选标题。笔记追加不带时间，可选标题作为二级标题。阅读时分别显示为卡片或时间线，源码仍是 Markdown。

待办和问题可在标题旁或项目概览切换状态，变更会写回正文并生成历史版本。条目页完成或关闭时可附结论；完成后仍可追加或重新打开。全文编辑、历史、翻译、批注在「⋯」菜单中。

## 标题与状态

文首资料示例：

```markdown
---
title: '支持文件夹引用'
status: todo
---

具体说明。
```

`title` 和 `status` 必须是单行文字，可加英文引号。其他字段保留；阅读时隐藏文首资料。

| 目录 | 状态 | 显示文字 |
| --- | --- | --- |
| `todo` | `todo` / `doing` / `done` | 待办 / 进行中 / 已完成 |
| `issue` | `open` / `closed` | 待处理 / 已关闭 |
| `note` | 不要求 | 笔记 |

缺少 `title` 时依次取正文第一个一级标题、文件名；代码块里的标题不计。缺少状态显示「未设置」，不支持的状态显示「待调整」。文首格式错误或状态重复时，先编辑原文件再切换状态。

分类取决于项目下第一层目录名，忽略大小写和两侧空格。跨分类移动后，原状态保留，可能需要重新选择；移出分类目录或放入回收站后不再列入项目。

## 文件与文件夹引用

新建「文件／文件夹引用」可在其他位置放一个入口，原内容不复制。引用可改名、移动、收藏或删除；删除引用不删除原文件，添加内容需先打开原目录。

把 Markdown 文件引用放进分类目录，即可纳入项目。文件夹引用会收录目标目录及下级引用中的 Markdown；项目第一层的引用也可命名为 `todo`、`issue` 或 `note`。同一分类不重复列出同一个文件，循环引用会跳过。

从项目中追加或改状态会写回原文件，其他引用处刷新后可见。原文件删除或进入回收站后显示不可用。整库备份包含项目与引用关系。
