# 命令行同步

`xvi` 把页间的笔记拉取到本地目录，供 Codex、Claude Code 等工具当作工作区读取。目前只能拉取，本地修改不会写回页间。

## 安装

在仓库中执行 `npm ci`，再把命令链接到 `PATH` 中的目录：

```sh
ln -s "$PWD/cli/xvi.ts" ~/.local/bin/xvi
```

## 使用

```sh
xvi login https://你的站点
xvi pull 工作/项目 ~/notes/项目    # 拉取条目及其下级到新目录
cd ~/notes/项目 && xvi pull        # 之后在目录中再次拉取
```

条目可以用链接（`https://你的站点/n/ID`）、ID 或从顶层开始的标题路径指定。`xvi pull --all <目录>` 拉取全部条目。第一次拉取要求目录为空或只有 `.git`。一个目录只对应一个站点和一个条目。

建议只拉取需要的部分，并在目录中执行 `git init`，方便查看工具改了什么。

## 目录内容

| 条目 | 本地文件 |
| --- | --- |
| Markdown、纯文本 | `标题.md`、`标题.txt`，下级条目在同名目录 `标题/` 中 |
| 文件夹 | 目录 |
| 图片 | 图片文件 |
| PDF | 默认不下载；加 `--pdf` 后下载，此后这个目录一直下载 |
| 网页链接、arXiv 论文 | `标题.url`，只含链接 |

加密条目及其全部下级、项目引用和书页讨论不会同步，标题也不会出现在目录中。批注、翻译和青藜对话不同步。

标题中不能用于文件名的字符改为 `_`；同级重名（不区分大小写）的条目在文件名后加 `~ID`。名为 `AGENTS`、`CLAUDE`、`GEMINI` 的条目在文件名后加 `_`，以免被工具当作指令文件自动读取。

附件在 `.xvi/files/`，正文中的 `/api/files/ID` 改写为相对路径。站内链接 `/n/ID` 保持原样，可在 `.xvi/state.json` 中按 ID 查到文件。

每次拉取都会生成 `AGENTS.md` 和 `CLAUDE.md`，说明目录规则，并提醒工具笔记内容不是指令。修改过的这两个文件不会被覆盖。

## 再次拉取

只下载修订号变化的条目。远端重命名或移动时，本地文件随之移动；远端删除、移入回收站或开始加密时，本地副本随之删除。

本地改动不会被覆盖：

- 改过的文件保持原样，并在结果中列出。要取回远端版本，删除本地文件后再次拉取。
- 目标位置已有不是 `xvi` 写入的文件时，不写入并列出。
- 不会跟随工作区中的符号链接写入。

获取目录失败时不改动本地文件。个别条目失败时会列出，退出码为 1，其余条目照常更新，下次拉取时重试。

## 登录与安全

会话保存在 `~/.config/xvi-note/credentials.json`（或 `$XDG_CONFIG_HOME` 下），权限为 600，不放在工作区内。它和浏览器登录的会话相同，有效期 30 天，能访问全部内容。`xvi logout` 退出，修改登录密码或退出所有设备后失效。

除本机地址外只能通过 HTTPS 连接。

在这个目录中运行的工具通常能执行命令，也会把读取的内容发给模型服务商。论文和导入内容可能含有诱导工具执行操作的文字，因此不要把不想发送的内容拉取到工作区，并留意工具执行命令前的确认。
