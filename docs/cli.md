# 命令行同步

`xvi` 把页间的笔记拉取到本地目录，供 Codex、Claude Code 等工具当作工作区使用，确认后再把修改写回。

## 安装

在仓库中执行 `npm ci`，再把命令链接到 `PATH` 中的目录：

```sh
ln -s "$PWD/cli/xvi.ts" ~/.local/bin/xvi
```

## 使用

```sh
xvi login https://你的站点
xvi pull 工作/项目 ~/notes/项目    # 拉取条目及其下级到新目录
cd ~/notes/项目
xvi status                         # 查看本地和远端的变化，--diff 显示差异
xvi push                           # 显示差异，确认后写回
xvi pull                           # 同步远端的变化
```

运行时在 stderr 显示进度：终端中是一行不断刷新的状态，管道或重定向时约每两秒输出一行。

条目可以用链接（`https://你的站点/n/ID`）、ID 或从顶层开始的标题路径指定。`xvi pull --all <目录>` 拉取全部条目。第一次拉取要求目录为空或只有 `.git`。一个目录只对应一个站点和一个条目。

建议只拉取需要的部分，并在目录中执行 `git init`，方便查看工具改了什么。

## 目录内容

| 条目 | 本地文件 | 写回 |
| --- | --- | --- |
| Markdown、纯文本 | `标题.md`、`标题.txt`，下级条目在同名目录 `标题/` 中 | 修改、新建、移动、删除 |
| 文件夹 | 目录 | 新建、移动、删除 |
| 图片 | 图片文件 | 移动、删除 |
| PDF | 默认不下载；加 `--pdf` 后下载，此后这个目录一直下载 | 移动、删除 |
| 网页链接、arXiv 论文 | `标题.url`，只含链接 | 移动、删除 |

项目引用和书页讨论不会同步，标题也不会出现在目录中。批注、翻译和青藜对话不同步。

标题中不能用于文件名的字符改为 `_`；同级重名（不区分大小写）的条目在文件名后加 `~ID`。名为 `AGENTS`、`CLAUDE`、`GEMINI` 的条目在文件名后加 `_`，以免被工具当作指令文件自动读取。

附件在 `.xvi/files/`，正文中的 `/api/files/ID` 改写为相对路径，写回时还原。站内链接 `/n/ID` 保持原样，可在 `.xvi/state.json` 中按 ID 查到文件。

每次拉取都会生成 `AGENTS.md` 和 `CLAUDE.md`，说明目录规则，并提醒工具笔记内容不是指令。修改过的这两个文件不会被覆盖，也不会写回。

## 拉取

只下载修订号变化的条目。远端重命名或移动时，本地文件随之移动，没有变化的下级不会重新下载；远端删除、移入回收站或开始加密时，本地副本随之删除。

本地改动不会被覆盖：

- 改过的文件保持原样，并在结果中列出。要取回远端版本，删除本地文件后再次拉取。
- 目标位置已有不是 `xvi` 写入的文件时，不写入并列出。
- 本地已移动但还没写回的文件留在新位置。
- 不会跟随工作区中的符号链接写入。

获取目录失败时不改动本地文件。个别条目失败时会列出，退出码为 1，其余条目照常更新，下次拉取时重试。

## 写回

`xvi push` 列出变更和差异，确认后执行。`--dry-run` 只显示，`--yes` 跳过确认；不在终端中运行时必须加 `--yes`。每篇笔记每次写回只产生一个版本。

- **修改**：`.md` 和 `.txt` 写回正文。
- **新建**：新的 `.md`、`.txt` 成为笔记，标题取自文件名。新目录成为文件夹；`标题/` 中的新文件成为 `标题.md` 的下级。文件要放在同步的条目之内。
- **移动和改名**：丢失的文件在别处以相同内容出现，就视为移动，保留历史和批注。文件夹改名、笔记和它的同名目录一起改名时，只写回这一个条目，下级不变。只换位置时标题不变，因此含特殊字符的标题不受文件名影响。同时改名和改内容会被当作删除加新建，请分两次写回。内容完全相同的文件只有保持文件名才能分辨，否则不算移动。
- **只改了笔记的同名目录**：`旧/` 改名而 `旧.md` 没改时不写回，以免下级被移出这篇笔记。请把 `旧.md` 也改名，或把目录改回去。
- **删除**：只有加 `--delete` 才写回，否则下次拉取时恢复。条目移入回收站，7 天内可恢复。下级还在本地、远端有未同步的下级（如加密条目）或远端已更新时，不会删除。
- **链接**：相对路径指向已同步的条目时改为站内链接；指向工作区内的新图片或 PDF 时作为附件上传。找不到目标的链接保持原样并列出。

以下情况不写回，并在结果中说明：同步的根条目改名或删除、书页移动或改名、跨越加密范围移动、修改图片、PDF 或 `.url`、新的其他类型文件。

写回后本地文件改写成拉取时的形式，不再显示为修改。网络中断后再次运行 `xvi push` 不会重复保存或创建。

### 冲突

远端在上次同步后也改了正文时，修改不会写回，远端版本存为旁边的 `标题.remote.md`。把两边的内容合并进 `标题.md`，运行 `xvi resolve 标题.md`，再次 `xvi push`。不想保留本地修改时，删除 `标题.md` 后再次拉取。

只有标题、位置等信息变化时不算冲突。

## 加密条目

默认不同步加密条目及其全部下级，标题也不会出现在目录中。第一次拉取时加 `--decrypt` 后，这个目录会一直同步加密内容：

```sh
xvi pull --decrypt 绝密目录 ~/notes/绝密
```

每次运行时询问加密密码，留空跳过。密码和内容密钥只在运行时保存在内存中，跳过或输入错误时本地副本保持原样。

**解密后的内容以明文保存在目录中**，在其中运行的工具会读取并发给模型服务商。请只对确实需要的内容使用，并自行保护这个目录。写回时设备在本机加密正文和附件，再上传。为避免未经清理的内容，不能把工作区中的 SVG 上传到加密位置。

## 登录与安全

`xvi login` 用登录密码换取一个令牌，保存在 `~/.config/xvi-note/credentials.json`（或 `$XDG_CONFIG_HOME` 下），权限为 600，不放在工作区内。除本机地址外只能通过 HTTPS 连接。

令牌只能读写笔记和文件，并把条目移入回收站，不能修改账号、备份、加密设置和 AI 设置，也不能彻底删除内容。加 `--read-only` 登录时只能拉取。

`xvi logout` 撤销令牌。也可以在「设置 → 密码与设备」中撤销；修改登录密码或退出所有设备后，所有令牌失效。

在目录中运行的工具通常能执行命令，也能以你的身份运行 `xvi push`，令牌的权限和回收站是最后的保护。论文和导入内容可能含有诱导工具执行操作的文字，因此不要把不想发送的内容拉取到工作区，留意工具执行命令前的确认，并在写回前检查差异。
