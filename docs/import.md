# 导入文件夹

桌面网页版可把 Obsidian、Typora 等 Markdown 笔记文件夹导入页间。在「新建」中点「导入文件夹…」，或把文件夹、文件直接拖到窗口中（拖到正在编辑的正文里仍作为附件插入）。Android 应用和手机浏览器不提供此功能。

## 导入位置

导入目录时，在当前文件夹下新建「<目录名> 导入 日期」，所有内容放在其中，不与已有条目合并；导错了删除这个文件夹即可。只拖入几个文件时直接放进当前文件夹。

目标位置已加密时，文件和正文在本机加密后上传，与普通笔记相同；未解锁时先提示输入密码。

## 文件如何对应

| 文件 | 导入为 |
| --- | --- |
| `.md`、`.markdown` | Markdown 笔记，标题为文件名 |
| `.txt` | 纯文本笔记 |
| `.pdf` | PDF 条目 |
| PNG、JPEG、GIF、WebP、AVIF、SVG | 图片条目 |

其他类型、超过 1 MiB 的正文、超过 50 MB 或为空的文件会跳过，并在导入前列出。以 `.` 开头的文件和目录（如 `.obsidian`、`.git`、`.trash`）直接忽略。一次最多导入 2000 项，且不超过剩余空间。

目录成为文件夹，同级按名称排序，文件夹在前。「文件夹笔记」会合并：`项目.md` 旁边有 `项目/` 目录，或 `项目/项目.md` 位于自身目录中时，这篇笔记成为一个条目，目录里的内容放在它下面。

## 链接

Markdown 笔记中的链接在导入时改写：

- 图片 `![](img/a.png)`、`![](<带 空格.png>)`、`![[a.png]]`、`![[a.png|300]]` 改为站内图片；`|` 后的文字作为图片说明，数字尺寸忽略。
- 笔记链接 `[文字](其他.md)`、`[[其他]]`、`[[其他|别名]]` 改为站内链接；`#标题` 锚点暂不保留，链接到整篇笔记。
- 相对路径按笔记所在目录解析，找不到时再按笔记库根目录和文件名查找；`[[ ]]` 按名称查找，重名时取路径最短的。
- 网址、站内链接和代码中的内容保持原样。找不到目标的链接保持原文，导入后列出。

图片作为独立的图片条目保留在原目录位置，多篇笔记可以引用同一张图片。

## 中断与重试

导入时显示进度，可随时停止。每个条目的标识在导入开始时由本机生成，同一次导入中「继续导入」只补齐未完成和失败的部分，不会重复创建。关闭对话框后不再续传，已导入的内容保留在导入文件夹中。
