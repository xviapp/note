# arXiv 论文

## 导入与阅读

选择「新建 → 更多类型 → arXiv 论文」，粘贴 `arxiv.org` 的 HTML、摘要或 PDF 链接，例如 `https://arxiv.org/html/2503.01800v1`。标题留空时自动使用论文标题。导入固定版本的正文、公式、图片和许可信息，去掉站点导航；源网页的脚本、样式和外部图片不会在阅读区加载。图片保存在私有 R2，正文与图片均计入空间，随论文进入回收站和清理流程。

论文直接显示在主阅读区，保留 MathML 公式、参考文献和内部引用跳转；可以整理目录、重命名及添加 Markdown 子笔记，论文正文保持只读。青藜支持引用选中文字和公式、框选截图，以及通过「附上当前文件」选择全文或章节。附给 AI 的公式转成 LaTeX；长论文也可选择全文，预览显示估算 tokens，发送时按模型上下文容量检查，不会静默截断。

每次导入 HTML 最多 8 MiB、200 张不同图片，单张最多 10 MiB、图片合计最多 100 MB。图片较多时分几次请求下载，界面显示下载进度；某一步失败后再次点击导入会从中断处继续，6 小时内有效。支持 PNG、JPEG、GIF、WebP、AVIF、SVG；无法识别的图片、下载失败或空间不足时，不创建不完整论文。没有 HTML 的论文仍可通过 PDF 文件阅读。导入请求最多等待 90 秒，失败后可手动重试。

## 对照阅读与全文翻译

导入的论文可以「对照阅读」：全屏左右显示原文与译文，滚动任意一边，另一边按段落同步。点击「翻译全文」后按段落分批翻译（公式、引用和链接保持原样），每批完成即保存，停止或关闭后再次打开可从中断处继续，已翻译的段落不会重复计费；单段可重新翻译。也可以只翻译当前阅读的章节。

首次翻译前会根据标题、摘要和章节标题自动生成术语表，之后每一段都按其中的译名翻译；术语表可以编辑，改动后可只重新翻译用到这些术语的段落。

全文翻译完成后，译文会自动保存为论文的 Markdown 子笔记（公式写成 TeX，插图沿用论文图片），也可随时点「保存为子笔记」手动保存；同一语言再次保存会更新这篇子笔记，旧内容留在版本历史中；「翻完存为子笔记」可以关闭。

翻译同时发出 3 批请求，关闭对照阅读后仍在后台继续，工具栏显示进度，完成后提示。对照阅读会记住上次读到的段落，支持划词复制、翻译和问青藜，图片可点开放大。划词翻译记录可在「翻译记录」里一键导出为子笔记，按原文顺序排列。手机上一次显示一边，切换原文与译文时停在同一段。译文按论文和目标语言保存，随论文移入回收站、恢复或清理，也包含在整库备份中。

## SVG 图片

SVG 文件和论文内嵌 SVG 均作为独立矢量图片保存，保留路径、文字、渐变、裁剪和图内引用；可放大、下载、截图及作为助手附件。存储前通过 XML 和 CSS 解析清理为静态图，移除脚本、事件、动画、外部资源引用及嵌入的 HTML；不加载外部 DTD，不展开自定义实体。普通 SVG 上传同样执行清理，上限 10 MiB。阅读时保留矢量图，发送给助手时由浏览器绘制成 JPEG，原 SVG 不直接交给模型。

青藜的引用、附件与上下文规则见[青藜与翻译](assistant.md)。
