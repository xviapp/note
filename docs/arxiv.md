# arXiv 论文

## 导入与阅读

新建 arXiv 论文，粘贴 HTML、摘要或 PDF 链接，如 `https://arxiv.org/html/2503.01800v1`。标题留空时使用论文标题。没有 HTML 的论文可下载 PDF 后作为文件阅读。

导入固定版本的正文、公式、图片和许可信息，保存在私有 R2 并计入空间。阅读区保留公式、参考文献和内部跳转，正文只读，可添加子笔记。源网页脚本、样式和外部图片不会加载。

每次导入上限：HTML 8 MiB、200 张图片，单张 10 MiB、图片合计 100 MB。多图分批下载，中断后 6 小时内可继续；下载失败、格式不支持或空间不足时不创建残缺论文。单次请求最多等待 90 秒。

## 对照阅读与全文翻译

「对照阅读」并排显示原文与译文，按段落同步滚动；手机切换原文、译文时保留位置。

可翻译全文或当前章节。翻译分批保存，关闭窗口后继续；停止后再打开可续传，已完成段落不重复计费，单段可重译。首次翻译会生成术语表，可编辑，并只重译用到改动术语的段落。

完成后可自动存为 Markdown 子笔记，也可手动保存。相同语言再次保存会更新原子笔记，旧内容留在历史版本。「翻完存为子笔记」可关闭。划词翻译记录也可按原文顺序导出为子笔记。

青藜可引用选文、公式、截图、全文或章节。公式转为 LaTeX，发送前检查上下文容量，详见[青藜与翻译](assistant.md)。

## SVG 图片

SVG 保留矢量路径、文字、渐变、裁剪和内部引用；入库前清除脚本、事件、动画、外部资源及嵌入 HTML，不展开外部 DTD 或自定义实体。普通 SVG 上传上限为 10 MiB。

阅读、放大和下载使用矢量图；发给青藜时由浏览器转成 JPEG。
