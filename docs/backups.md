# 备份与恢复

在网页版「设置 → 备份与恢复」导出 ZIP，或选择备份文件预览并恢复。Android 客户端不提供整库备份入口，请在网页版操作。

## 备份范围

备份包含笔记与目录、日记和书籍资料、项目及引用关系、随手记及图片、文件夹图标、回收站内容、附件、保留的历史版本、收藏、阅读位置、批注、青藜对话及附件、翻译与原文位置；不含登录密码、会话、AI 密钥和本机缓存。

恢复时新建「备份恢复 日期」目录，原回收站内容放在其下的「原回收站」，全局对话恢复为「青藜全局对话（恢复）」笔记，当前资料与账号设置保留，恢复的文件计入空间。

## 导出与恢复

导出时服务端在一个 D1 事务中读取清单并保留文件引用，期间的编辑或清理不会移除正在下载的附件。ZIP 在网页版逐个文件生成（支持 Zip64）：支持 File System Access API 的桌面浏览器流式写入，其他浏览器在内存中生成，超过 256 MiB 时提示改用桌面 Chrome。

恢复会检查路径、重复项、CRC、大小、目录循环和引用完整性，逐个上传文件后在一个 D1 事务中写入目录和记录；文件、版本、节点使用新 ID，正文链接和翻译位置同步映射。中断不会留下半棵目录，重试复用已上传的文件；任务最长保留 24 小时，清单上限 16 MiB。

## 加密内容

备份中的加密内容保持密文，需要原加密密码。恢复后在备份设置页解锁并点击「修复加密内容」，由设备重新映射正文中的附件和内部链接。未加密内容在 ZIP 中仍为明文，详见[本地加密](encryption.md)。

## 保管与验证

定期导出 ZIP，保存在部署环境之外。本机缓存、未同步草稿和待发送内容不属于云端备份；登录密码、AI Key、实例配置及 Android 签名需另行保管。

首次存入重要资料前，在测试实例创建笔记、内部链接、附件和加密笔记，导出后恢复到新实例，确认正文、历史、附件及修复后的链接可用。也可恢复到原库的新目录验证，需要预留额外空间。

D1 的 [Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/) 只恢复数据库，不恢复 R2 文件；清理流程可能已删除旧引用对应的对象，单独回退数据库不能保证资料完整。日常恢复使用包含文件的整库 ZIP，无需删除全文索引或导出 D1。
