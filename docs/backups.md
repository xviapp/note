# 备份与恢复

在网页版「设置 → 备份与恢复」导出 ZIP，或选择备份文件恢复。Android 请用浏览器操作。

## 备份范围

包括笔记、目录、日记、书籍、项目与引用、随手记、图片和附件、回收站、保留的历史版本、收藏、阅读位置、批注、青藜对话及翻译。

不包括登录密码、会话、AI Key、实例配置、本机缓存和未同步草稿，需另行保管。

## 导出与恢复

支持 File System Access API 的桌面浏览器直接写文件，其他浏览器在内存中生成 ZIP；超过 256 MiB 时改用桌面 Chrome。

恢复会新建「备份恢复 日期」目录，保留当前资料。原回收站内容放入「原回收站」，全局对话恢复为独立笔记。文件和节点使用新 ID，链接随之改写；恢复的内容占用额外空间。

导出期间文件引用会保留，避免被清理。恢复先检查清单和文件，上传后一次性写入目录，中断可重试。任务保留 24 小时，清单上限 16 MiB。

## 加密与保管

加密内容以密文备份，需要原密码。恢复后在同一页面解锁并点击「修复加密内容」，改写正文中的附件和内部链接。未加密内容在 ZIP 中仍为明文。

定期导出并保存在部署环境之外。首次使用时，可在测试库恢复一份含笔记、附件和加密内容的备份，检查正文、历史及链接。

D1 的 [Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/) 不恢复 R2 文件；旧文件可能已被清理，单独回退数据库不能保证资料完整。
