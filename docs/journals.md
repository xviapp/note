# 日记本

新建日记本后，点击月历日期书写，或点「写今天」。写过的日期带底色，有草稿的日期带圆点，今天加框。可以补写过去的日期，不能写将来；日期按设备时区计算。

每天一篇 Markdown，自动放入年、月目录。同一天的多次记录追加到已有日记；另一台设备先创建了当天日记时也不会重复创建。标题旁的箭头可打开前一篇或后一篇。

## 追加记录

在日记底部写文字、选照片，点击「追加」或按 Ctrl/Cmd+Enter。标题可选，记录以「### 14:05 · 标题」写入正文。需要修改全文时点「编辑正文」。

照片支持 PNG、JPEG、GIF、WebP、AVIF，可多选，保存后作为正文图片和附件保留。照片在后台上传，期间可继续写字，也可先点「追加」，上传完成后再提交。

文字和照片暂存在本机，加密日记的草稿也加密。离线时可先写，联网后上传；中断后重新打开会继续处理已点过保存的记录。上传或保存失败时保留内容，可重试或移除失败照片。结果尚未确认时不能修改输入，以免重复追加。退出登录会清除本机暂存。

## 日期与移动

改标题或在日记本内移动不影响日期对应。移出日记本或放入回收站后，当天可重新创建日记；恢复回收站中的旧日记时，它作为普通笔记保留。

日记支持附件、历史版本、离线阅读、加密和青藜。日记本及日期对应关系包含在整库备份中。

Android 长按图标可打开「今日记」，支持离线暂存和加密日记未解锁时先记下，见[快捷入口](android.md#快捷入口)。
