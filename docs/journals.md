# 日记本

选择「新建 → 日记本」创建一个按日历书写的目录。打开日记本显示月历：写过日记的日期带圆点，今天加框。点击某一天，已有日记就直接打开，没有就新建当天的日记并进入编辑。「写今天的日记」按钮对应今天。可以补写过去的日期，不能写将来的日期；日期按设备所在时区计算。

每天一篇 Markdown 日记，标题为日期（如 `2026-10-07`），自动放入 `2026年/10月` 子目录。日记与日期的对应关系单独保存（`journal_entries`），所以在日记本内改标题或移动位置不影响日历。日记移出日记本或放入回收站后，这一天可以重新书写；从回收站恢复的旧日记作为普通笔记保留。

## 模板

日历上方始终显示模板选择和「管理模板」。选择「仅日期标题」时，日记以 `# 2026年10月7日 星期三` 开头；所选模板按日记本保存在本设备上。

在「管理模板」中可以新建、选用、编辑、重命名或删除模板。新建和编辑使用 Markdown 编辑器，可以插入日期占位符并预览今天的内容；新建模板保存后自动选用。模板存放在日记本的 `templates` 目录中，也可以作为普通 Markdown 笔记打开。模板只影响之后创建的日记，已有日记保持原样；删除当前模板后回到「仅日期标题」。模板中可以使用：

| 占位符                           | 示例          |
| -------------------------------- | ------------- |
| `{{date}}`                       | 2026-10-07    |
| `{{日期}}`                       | 2026年10月7日 |
| `{{星期}}`                       | 星期三        |
| `{{year}}` `{{month}}` `{{day}}` | 2026、10、7   |

## 快捷记录

打开每日的日记后，正文阅读区底部提供居中且限制宽度的快捷记录框，无需打开全文编辑器。标题和正文输入框等宽，正文输入框至少 104px 高，可拖动调高；标题可选，内容必填；标题作为二级标题，内容追加到正文末尾。回车换行，点击「追加」或按 Ctrl/Cmd+Enter 保存。新建当天日记后直接进入阅读和快捷记录，也可以通过「编辑正文」修改全文。

输入会暂存在本设备，重新打开同一篇日记可继续；加密日记的输入也在本设备上加密保存。离线时可以查看和保留输入，联网后才能追加。保存失败时输入保留，版本冲突时再次追加会读取最新正文，附件和原有内容保持完整。

## 其他

日记就是普通笔记，编辑、附件、历史版本、离线阅读和本地加密照常可用；加密的日记本中，日记和模板都在本设备上加密。日记页保留青藜悬浮入口，和青藜对话时会告诉它这是哪一天的日记。整库备份包含日记本和日期对应关系。
