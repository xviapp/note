# 日记本

选择「新建 → 日记本」创建一个按日历书写的目录。打开日记本显示月历：写过日记的日期带底色，有未提交记录的日期下方带小圆点，今天加框。宽屏上月历右侧列出最近的日记（日期、星期和摘要，多条记录之间以「·」分隔），窄屏上列在月历下方。点击某一天，已有日记就直接打开；未写的日期先进入待记录页，输入框自动获得焦点，首次追加时才创建当天日记。不输入就返回不会创建文件或标记已写；未提交的标题、内容按日记本和日期保存在本设备，再次打开该日期可恢复，加密日记本的草稿同样加密。日记本页面标题右侧的「写今天」按钮对应今天，使用相同流程；今天已写时按钮显示为「续写今天」。保存失败保留输入，可重试；若另一台设备已创建当天日记，会将记录追加到已有正文。可以补写过去的日期，不能写将来的日期；日期按设备所在时区计算。

每天一篇 Markdown 日记，标题为日期（如 `2026-10-07`），自动放入 `2026年/10月` 子目录。打开日记时，页面标题显示为「2026年10月7日 星期三」，类型显示为「日记」，正文开头与之相同的一级标题在阅读时不再重复显示；位置栏省略年、月目录。标题右侧的左右箭头打开前一篇和后一篇日记（跳过没写的日期）。日记与日期的对应关系单独保存（`journal_entries`），所以在日记本内改标题或移动位置不影响日历。日记移出日记本或放入回收站后，这一天可以重新书写；从回收站恢复的旧日记作为普通笔记保留。

## 快捷记录

打开每日的日记后，正文阅读区底部提供居中且限制宽度的快捷记录框，无需打开全文编辑器。未使用时只显示一行输入框，获得焦点或已有输入后再显示标题框和「追加」按钮。宽屏上标题和正文输入框等宽，正文输入框至少 104px 高，可拖动调高；手机上正文框约 80px 高；标题可选，内容可以只写文字、只添加照片或两者都有；点击「照片」可一次选择多张 PNG、JPEG、GIF、WebP 或 AVIF 图片，上传后显示缩略图，可在提交前移除。每条记录以「### 14:05 · 标题」开头追加到正文末尾（不写标题时只有时刻），照片作为正文图片和附件保存；阅读时按时刻排成一天的流水：左侧是时刻，右侧是标题和内容；记录不进入「本篇目录」。回车换行，点击「追加」或按 Ctrl/Cmd+Enter 保存。新建当天日记后直接进入阅读和快捷记录，也可以通过「编辑正文」修改全文。

提交按钮在输入区获得焦点或已有输入时显示：宽屏放在正文输入框右侧，手机上与标题框同行；青藜悬浮入口位于追加区上方。输入和已上传照片会暂存在本设备，重新打开同一篇日记可继续；加密日记的输入、照片和草稿也按日记的密钥保存。离线时可以查看和保留输入，联网后才能上传照片和追加。保存期间离开页面会提示稍候。保存失败时输入和照片保留：结果未确认（断线或服务器错误）时锁定输入，只能原样重试以免重复记录，刷新或重新打开后也会保留这次提交的重试标识；明确失败（如笔记已锁定、内容过大）时输入保持可编辑；版本冲突时再次追加会读取最新正文，附件和原有内容保持完整。

## 其他

日记就是普通笔记，编辑、附件、历史版本、离线阅读和本地加密照常可用。日记页保留青藜悬浮入口，和青藜对话时会告诉它这是哪一天的日记。整库备份包含日记本和日期对应关系。
