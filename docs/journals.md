# 日记本

选择「新建 → 日记本」创建。月历中，写过日记的日期带底色，有草稿的日期带小圆点，今天加框。点击日期打开日记；空白日期在首次追加时才创建，未提交的输入保存在本设备，加密日记本的草稿同样加密。「写今天」可进入今天，已写时显示「续写今天」。若另一台设备已创建当天日记，记录会追加到已有正文。可补写过去，不能写将来，日期按设备时区计算。Android 长按页间图标选「今日记」，在当前应用上方弹出浮动窗口，直接写标题、正文和照片，保存后在后台记入今天的日记：日记本在「设置 → 保存位置 → 今日记保存到」中选择（账号设置，各设备共用），默认为最近写过的日记本，见 [Android 客户端](android.md#快捷入口)。

每天一篇 Markdown 日记，标题为日期（如 `2026-10-07`），自动放入 `2026年/10月` 子目录。打开日记时，页面标题显示为「2026年10月7日 星期三」，类型显示为「日记」，正文开头与之相同的一级标题在阅读时不再重复显示；位置栏省略年、月目录。标题右侧的左右箭头打开前一篇和后一篇日记（跳过没写的日期）。日记与日期的对应关系单独保存（`journal_entries`），所以在日记本内改标题或移动位置不影响日历。日记移出日记本或放入回收站后，这一天可以重新书写；从回收站恢复的旧日记作为普通笔记保留。

## 快捷记录

在日记底部直接追加文字或照片，标题可选，无需进入全文编辑。照片可多选，支持 PNG、JPEG、GIF、WebP、AVIF，提交前可移除；保存后同时作为正文图片和附件保留。每条记录以「### 14:05 · 标题」追加到正文末尾，未填标题时只记时刻。阅读时按时间排列，记录不进入「本篇目录」。回车换行，点击「追加」或按 Ctrl/Cmd+Enter 保存；「编辑正文」可修改全文。

照片选好后先显示本机预览并逐张在后台上传，上传期间可继续输入；未传完时也可以点「追加」，传完后自动保存（按钮显示「保存中…」）。某张照片上传失败时可点照片重试或移除，已请求的保存会取消并保留内容。输入、已上传和未上传的照片都暂存在本设备（未上传的照片放在 IndexedDB，加密日记按日记密钥加密，退出登录时清除）；加密日记的草稿同样加密。页面关闭或应用被系统结束时，下次打开会接着上传，已点过保存的记录在传完后自动补记。离线时可写字和选照片，联网后才上传和追加。Android 今日记窗口可在加密日记本未解锁时先记下，解锁后自动记入，见 [Android 客户端](android.md#快捷入口)。保存期间离开页面会提示稍候。保存失败保留输入和照片：结果未确认时锁定输入，原样重试以免重复，重新打开也能继续；明确失败时可修改输入；版本冲突后再次追加会读取最新正文，保留原内容和附件。

## 其他

日记就是普通笔记，编辑、附件、历史版本、离线阅读和本地加密照常可用。日记页保留青藜悬浮入口，和青藜对话时会告诉它这是哪一天的日记。整库备份包含日记本和日期对应关系。
