# 日记本

选择「新建 → 日记本」创建一个按日历书写的目录。打开日记本显示月历：写过日记的日期带圆点，今天加框。点击某一天，已有日记就直接打开，没有就新建当天的日记并进入编辑。「写今天的日记」按钮对应今天。可以补写过去的日期，不能写将来的日期；日期按设备所在时区计算。

每天一篇 Markdown 日记，标题为日期（如 `2026-10-07`），自动放入 `2026年/10月` 子目录。日记与日期的对应关系单独保存（`journal_entries`），所以在日记本内改标题或移动位置不影响日历。日记移出日记本或放入回收站后，这一天可以重新书写；从回收站恢复的旧日记作为普通笔记保留。

## 模板

日记本中的 `templates` 目录（创建时自动生成）里的 Markdown 文件都可以作为模板，在日历上方选择，所选模板保存在本设备上。没有模板或选择「默认」时，日记以 `# 2026年10月7日 星期三` 开头。模板中可以使用：

| 占位符                           | 示例          |
| -------------------------------- | ------------- |
| `{{date}}`                       | 2026-10-07    |
| `{{日期}}`                       | 2026年10月7日 |
| `{{星期}}`                       | 星期三        |
| `{{year}}` `{{month}}` `{{day}}` | 2026、10、7   |

## 其他

日记就是普通笔记，编辑、附件、历史版本、离线阅读和本地加密照常可用；加密的日记本中，日记和模板都在本设备上加密。和青藜对话时会告诉它这是哪一天的日记。整库备份包含日记本和日期对应关系。
