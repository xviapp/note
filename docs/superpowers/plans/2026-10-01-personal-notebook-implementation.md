# 单人笔记库实施计划

依据已确认的设计稿实施。用户已明确要求开始实施；由当前代理按以下顺序完成代码、验证和使用说明。

## 技术选择

前端采用 React、TypeScript 和 Vite，服务端使用 Cloudflare Workers 的请求处理接口，数据使用 D1 和私有 R2。正文渲染采用经过安全处理的 Markdown 组件，编辑器和 PDF 阅读器按需加载。测试使用真实 workerd 的 D1、R2 绑定和浏览器端到端测试。

界面以长时间阅读为目标：白色正文区域、浅蓝灰侧栏、深蓝文字和低饱和蓝色操作色。颜色为纸白 #ffffff、侧栏 #f2f5f9、正文 #24344b、次要文字 #69788c、强调 #315d96、边界 #dfe5ed。中文使用系统无衬线字体；正文和标题依靠字号、字重和留白区分。电脑为树、正文、按需展开的标题目录，手机通过抽屉访问树。避免装饰性卡片和大面积品牌展示。

## 执行顺序

1. 建立可在本地运行的 Worker、前端和数据库迁移；验证密码计算在 workerd 中的兼容性，记录远端免费 CPU 验证边界。
2. 实现单次初始化、密码登录、会话失效、修改密码与部署端重置，加入来源检查和登录频率限制。
3. 实现节点树、不可变正文和附件对象、容量预留、并发版本检查、私有文件与 PDF 分段读取。
4. 实现回收站、有限历史版本、引用安全的垃圾清理、收藏、最近访问和阅读位置同步。
5. 完成电脑和手机界面，包括默认预览、单篇文件编辑确认、源码编辑、标题目录、图片放大和 PDF 阅读。
6. 验证权限隔离、保存冲突、空间边界、恢复、密码重置，以及电脑和手机的完整阅读编辑流程。
7. 提供本地启动、初始化、Cloudflare 配置、部署、密码重置和远端登录性能验证说明；提交完整代码及验证记录。

## 验证与交付边界

集成测试覆盖真实 D1 事务和 R2 对象生命周期，浏览器测试覆盖初始化到保存、恢复和退出的实际交互。构建、类型检查和测试通过后交付可部署项目。

云资源创建、正式部署和付费套餐开通与本地实现分开处理。没有远端测量结果时，不把本地运行通过表述为已满足 Cloudflare 免费版 CPU 限制。密码保护参数不因免费目标被静默降低。

## 完成与验证记录（2026-10-01）

上述 7 个本地实施阶段均已完成，包括单人密码入口、树形笔记、PDF / 图片节点及附件、文件预览与单篇编辑确认、回收站、有限历史、收藏与最近访问、阅读位置、容量控制、密码管理和维护脚本。详细运行方式见根目录 README。

以下是初始版本的验证记录；后续已取消全局只读模式，仅保留文件编辑确认，设置、对话和目录整理不受编辑模式限制。当前功能与测试范围见 README。

初始验证结果：

- `npm run build`：通过，包含前后端 TypeScript 检查；编辑器、图片查看器、PDF 查看器及 PDF Worker 独立打包。
- `npm test`：18 项 workerd / D1 / R2 集成测试通过。覆盖来源与访问控制、并发初始化、会话撤销、密码修改及重置保留数据、树环路、正文并发与幂等、版本恢复、原子容量预留、对象引用、回收站独立批次、进度版本冲突和上传失败清理。
- `npm run test:e2e`：10 项浏览器测试通过，分别在 1440 × 960 和 390 × 844 尺寸验证默认预览、两级确认、源码 / 预览切换、保存与历史、收藏与回收恢复、离开草稿保护、新标签页只读、PDF / 图片、阅读位置与冲突草稿、密码修改和退出所有设备。
- `npm audit`：生产与开发依赖合计 0 个已知漏洞。
- `npx wrangler deploy --dry-run`：通过，Worker 约 52 KiB（gzip 约 13 KiB）；只检查本地部署包，没有创建或修改远端资源。
- `npm run reset-password -- --local`：在新建的本地数据库上成功执行；初始化令牌已轮换。笔记保留和旧会话撤销另由集成测试验证。
- 已查看电脑、手机阅读页和 PDF 预览截图。手机端修复了目录跳转引用旧 DOM 的问题；进度保存标题内相对位置，避免长章节总是回到标题开头。

测试主动中断上传和关闭浏览器连接时，本地 workerd 会输出断流 / broken pipe 日志；对应失败处理及容量释放断言通过。测试库、测试令牌与日常本地开发库隔离，不向用户库写入示例笔记。

初始交付时尚未执行远端部署；当时 600,000 次 PBKDF2 的本地 wall time 约 55–65 ms，仅证明本地运行时支持。用户随后授权部署，已创建生产资源并完成云端验证；云端 PBKDF2 上限导致密码计算迁至浏览器，迭代次数保留，服务端使用独立密钥校验。当前部署和实测免费额度边界见 [Cloudflare 部署验证](../../cloudflare-deployment.md)。
