# 文件助手

每个文件独立保存一组会话；Markdown、纯文本、PDF、图片和链接节点都可使用。助手只接收主动发送的问题、文件附件、引用文字、框选截图，以及本文件最近的会话，不自动上传文件全文或访问链接网页。

## 交互

- 阅读工具栏或右下角悬浮入口打开助手。提供悬浮、贴边、最大化三种窗口模式：悬浮支持鼠标/触摸拖动和方向键移动，贴边在宽屏下与阅读区并排、窄屏下覆盖阅读区，最大化填满可见页面并可还原到之前的模式。切换和收起保留同一文件的草稿、待发送附件和对话；根据可见视口调整边界，截图时隐藏助手。
- 引用阅读区选中的文字；PDF 加入可选择的文字层，扫描 PDF 使用截图。
- 内置截图渲染当前阅读区域，鼠标或触摸框选，可预览、移除，再发送。
- 回复流式显示，可停止；中断和失败明确标识，保留已收到的内容。
- 每条完整回复可保存为源文件下的 Markdown 子笔记，无需编辑确认，重复点击返回同一笔记。所有节点支持子节点，既有循环检测、回收站和版本规则继续生效。
- 设置里配置 DeepSeek API Key，使用支持文字及图片的 deepseek-flash，并可测试连接、清除配置。

## 服务端

- Worker 固定请求 DeepSeek 官方地址。凭据通过 APP_SECRET 派生的 AES-GCM 密钥加密存入 D1，设置接口只返回是否配置，不回传密钥。
- D1 保存会话、消息索引和请求锁，R2 保存消息正文与截图，计入现有容量统计。删除到回收站时保留会话，永久删除或清空会话后由既有清理流程回收文件。
- 所有接口要求登录、写请求校验来源。仅编辑文件正文、附件或恢复历史版本要求单篇文件编辑确认；设置、聊天、生成子笔记和整理目录无需编辑模式。清空会话、删除等操作保留各自的确认。
- 每文件同时生成一条回复，请求标识防重复调用；调用限时，历史上下文取最近 20 条完整消息并限制总长度。截图最多 1 MiB，问题最多 8,000 字符，引用最多 20,000 字符。历史分批加载，不自动删除旧会话。
- SSE 在独立模块解析，正确处理跨网络分块、异常和取消；失败不自动重试付费请求。

## 实施与验证

1. 添加增量数据库迁移、共享消息类型、凭据及 DeepSeek 适配器。
2. 实现会话历史、流式生成、清空、导出，以及容量与清理引用。
3. 接入设置、响应式助手、文字选择、截图框选和 PDF 文字层，沿用三套主题。
4. Worker 集成测试验证隔离、权限、加密、上下文、流式失败、导出和清理；浏览器测试验证电脑/手机引用、截图、阅读与 Markdown 导出。未提供真实 API Key 时使用受控测试响应，不消耗用户额度。

## 文件附件扩展

用户确认同时支持附上当前文件和另选本地文件。读取当前 Markdown / 纯文本快照，PDF 使用已有 PDF.js 在浏览器选页提取文字，文字很少的页面自动渲染为图；整页图片模式用于公式、图表和复杂排版。发送前预览内容、页码、图片数量，可以移除。每次最多 3 个文件、60,000 字符和 6 张文件图片；最多选择 200 页，超出限制要求调整选择，不静默截断。

原文件和压缩后的图片经登录保护、无需编辑确认的聊天上传接口进入现有 R2 存储，实际发给 DeepSeek 的只有文字及图像内容。`assistant_message_files` 引用表让原文件、页面图片随消息保留，清理与全库容量统计统一处理。文字快照和页码范围存入消息正文，聊天历史可展开查看或下载原文件。上下文调整为 120,000 字符、8 张图片，保证本次 6 张附件图片及额外截图均能发送。会话及导出归属仍是打开助手的源文件。

验证涵盖只读上传、类型和大小边界、选页标记、最新图片完整性、共享原件与垃圾回收，以及电脑/手机的当前文件、本地文本/图片、PDF 文字提取、选页转图和无文字页面回退。浏览器测试使用真实 PDF.js 处理文件；DeepSeek 响应仍由测试替身提供。
