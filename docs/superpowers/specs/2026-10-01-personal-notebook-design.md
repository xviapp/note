# 单人私人笔记库设计草案

本项目是一个适配电脑和手机的私人笔记 Web 应用，以查阅资料为主。首次使用设置一个密码，后续登录后浏览自己的笔记树。部署采用 Cloudflare Workers、D1 和 R2，以尽量使用免费额度为目标。

本文汇总已经确认的功能，以及保留期限、同步行为和容量控制的默认值。用户已确认按此设计实施；实现与验证结果见实施计划和 README。本文保留设计决策，不代表远端部署或免费 CPU 验证已经完成。

## 已确认的首版范围

| 方面       | 设计要求                                                                        |
| ---------- | ------------------------------------------------------------------------------- |
| 访问       | 单人模式；首次设置密码，以后只输入密码登录；所有笔记和文件都需要登录才能访问    |
| 组织       | 树形结构；纯目录和 Markdown、纯文本笔记都可以包含子节点，笔记本身可以有正文     |
| 内容       | Markdown、纯文本、PDF、图片、外部网址；PDF 和图片可作为树节点，也可作为笔记附件 |
| 链接       | 外部网页在新标签页打开；内部笔记链接在当前阅读区跳转，重命名和移动后继续有效    |
| 阅读       | 默认直接展示只读预览；支持 Markdown 标题目录、图片点击放大和阅读位置记忆        |
| 编辑       | 全库编辑和单篇正文编辑分别确认；电脑使用源码加预览，手机切换源码和预览          |
| 恢复       | 回收站；少量正文历史版本，可查看并恢复                                          |
| 快捷访问   | 收藏和最近访问                                                                  |
| 密码管理   | 修改密码、退出所有设备、通过部署端重置忘记的密码                                |
| 部署和容量 | Workers、D1、R2；统计全库用量，提供容量上限和接近上限的提示                     |

首版采用单人模式和全库容量管理。全文搜索、整库导出和恢复导入未纳入本稿的首版功能。

## 建议默认值

以下数值作为当前实现的默认值；其中全库容量可以在设置中调整。

| 项目         | 默认值和含义                                                                        |
| ------------ | ----------------------------------------------------------------------------------- |
| 回收站       | 删除后保留 7 天，允许提前永久删除                                                   |
| 正文版本     | 每篇保留最近 5 个历史版本，另有 1 个当前版本                                        |
| 最近访问     | 展示最近访问的 20 个不同节点，按最后打开时间排序                                    |
| 阅读位置同步 | 本地及时记录；有变化时云端最多每 30 秒同步一次，切换笔记时补写                      |
| 登录状态     | 会话最长有效 30 天；退出、修改密码或部署端重置可提前使其失效                        |
| 全库内容容量 | 默认 8 GB，即 8,000,000,000 字节，可在设置中调整                                    |
| 用量提示     | 达到容量上限的 80% 时提示；达到上限后限制新增占用                                   |
| 单文件上传   | 默认最大 50 MB；Markdown 和纯文本正文默认最大 1 MiB；部署配置可调，仍受平台上限约束 |

容量统计包括当前正文、历史正文、附件、文件节点、回收站和等待清理的对象。同一个物理对象被多处引用时只计一次；上传中的预留容量单独展示并参与额度检查。仅修改引用关系而没有真正释放对象时，不虚报空间已释放。

## 阅读与编辑状态

“只读”约束正文、笔记树和附件的修改。收藏、最近访问、阅读进度及阅读界面设置属于阅读辅助记录，在只读状态下可以更新。密码管理使用独立的身份验证和操作确认。

| 状态                   | 内容区                                | 可执行的资料操作                                             |
| ---------------------- | ------------------------------------- | ------------------------------------------------------------ |
| 默认阅读               | Markdown 渲染结果、纯文本、PDF 或图片 | 浏览、打开链接、查看附件和历史版本、使用阅读辅助功能         |
| 全库编辑已确认         | 正文仍然预览                          | 新建、重命名、移动节点；管理文件节点；删除、恢复和整理资料   |
| 当前笔记编辑已确认     | 电脑显示源码和预览；手机切换两个视图  | 修改当前 Markdown 或纯文本正文、编辑其附件、恢复该篇历史版本 |
| 保存或取消后           | 当前笔记恢复只读预览                  | 保留本页的全库编辑状态，可以继续整理资料                     |
| 退出全库编辑或重新加载 | 回到默认阅读                          | 重新编辑需要重新确认                                         |

编辑状态只属于当前页面，不通过阅读进度同步到其他设备。编辑器按需加载，初始阅读界面直接展示内容。

修改正文或其附件时，附件列表也属于该次编辑的草稿，和正文一起保存。取消编辑不保留草稿上传产生的正式附件引用，临时文件进入清理流程。新建独立 PDF、图片节点使用全库编辑确认。

保存采用明确的保存按钮。保存成功后退出单篇编辑；失败或发生并发冲突时保留当前编辑内容。应用内离开未保存的笔记时，提供保存、放弃和继续编辑；浏览器刷新或关闭使用其支持的离开提示，不能承诺所有手机浏览器都会显示提示。重新加载后始终从只读状态进入。

## 笔记树与内容

节点类型为目录、Markdown、纯文本、PDF、图片和外部链接。目录和两种文本笔记可以包含子节点；PDF、图片和外链为叶子节点。附件归属于笔记，不自动出现在树中。附件可以另建一个引用同一文件的树节点，不重复上传该文件。

每个节点具有稳定标识、标题、类型、父节点和同级顺序。移动不能形成环，也不能把节点放进叶子节点。移动和重命名不改变节点标识。电脑可使用拖动及菜单移动；手机提供明确的移动到目录操作。根节点列表和子节点列表按展开需要加载。

内部链接保存目标节点标识。目标在回收站时显示可恢复的删除状态；永久删除后显示目标不存在。外部链接仅接受 http 和 https 网址，打开时隔离新窗口与本站，界面展示网址以便辨认目标。

Markdown 展示标题、列表、代码、表格、链接和图片；渲染后的任务复选框在阅读时不能修改笔记。原始 HTML 和危险链接经过限制及清理。纯文本按原文展示。PDF 提供页码跳转和缩放；图片提供适应屏幕、缩放及手机双指手势。上传的主动内容不作为同源网页执行，不支持预览的附件提供下载。

## 回收站与历史版本

删除父节点前展示会受影响的子节点数量。确认后，父节点与当前有效子树作为一个删除批次进入回收站，保留原有层级、内容、附件和历史版本。此前已经单独删除的子节点保留自己的删除批次和到期时间，不因删除父节点而自动延长保留期。

删除动作不立即回收存储。默认 7 天内可恢复整个删除批次；原父节点已经不存在或仍处于回收站时，恢复到根层级并提示原因。永久删除需要全库编辑状态和额外确认，列出涉及的节点数。永久移除父节点不能级联删除另一个保留期未到的删除批次，后者恢复时按缺失父节点处理。过期后停止提供恢复操作，清理由后台分批执行；处理中的占用继续展示为等待清理。

历史版本用于 Markdown 和纯文本笔记。每次手动保存且正文或附件引用发生变化时，将原来的当前版本纳入历史；没有实际变化的保存不产生新版本。快照记录正文、该版本的附件引用和保存时间，附件使用原来的不可变对象，避免为每个版本复制二进制文件。

查看历史不需要进入编辑。恢复历史需要全库编辑与该篇笔记编辑确认，并先处理尚未保存的编辑内容；恢复会产生新的当前版本，并将恢复前的当前版本纳入历史，仍保留最近 5 个历史版本。恢复历史不改变节点的位置、子节点和当前标题。

回收站到期、永久删除或旧版本超出保留数量时，只有已没有任何当前节点、其他版本或回收站引用的对象才可以实际删除。仍被历史版本引用的附件会继续占用空间。正文历史不提供图片、PDF 文件本体的编辑版本管理。

## 阅读位置与快捷访问

Markdown 记录当前位置的标题锚点和段落附近位置，纯文本记录段落附近位置，两者都记录滚动比例；PDF 记录页码和页内位置。不能只记录设备相关的像素偏移。笔记更新后先尝试匹配可用锚点，匹配失败则使用有效范围内的比例或页码。

打开笔记时读取云端最近确认的位置，并允许电脑与手机接续阅读。当前设备及时维护自己的阅读状态；只有位置变化且页面正在阅读时才节流同步。切换节点或页面进入后台时尝试补写，本地保留尚未确认的进度以供下次读取。

阅读状态有自己的更新版本号。旧设备积压的进度不能无条件覆盖另一设备较新的进度；只有当前正在发生的阅读行为才可以继续更新。后台页面不持续上报。图片与外链只记录最近访问，不记录正文滚动位置。

收藏指向原节点而不复制内容，在只读模式下可以添加和取消。收藏顺序默认按添加时间倒序。最近访问按主动打开的节点去重更新，预加载、展开目录以及 PDF 的分段请求不算一次新的访问。

进入回收站的节点从收藏和最近访问入口隐藏，恢复后原有引用可以重新显示；永久删除后清理相关引用。阅读历史是单人私有数据，不对未登录访问者开放。

## 页面布局与阅读辅助

电脑界面使用左侧笔记树和右侧阅读区。侧栏提供全部笔记、收藏、最近访问、回收站和设置入口。手机以阅读区为主，笔记树通过抽屉打开，并保留返回上级与当前位置的提示。

Markdown 标题目录来自当前渲染正文的标题，支持点击定位并标识当前阅读位置。电脑在阅读区侧边展开，手机通过按钮打开。历史版本的预览使用其自身的标题目录。

点击笔记中的图片或图片节点可以进入放大查看；电脑支持缩放与键盘关闭，手机支持手势缩放和明显的关闭入口。标题目录、图片查看和 PDF 阅读不会触发编辑解锁。

## 密码与会话

部署生成一次性初始化令牌，通过专属链接进入密码设置页；页面仅要求设置并确认密码。令牌不放在会被常规请求日志记录的查询参数里，完成设置后即失效。初始化在服务端原子提交，并发请求只有一次能够成功。未完成初始化时不开放笔记 API。

密码校验的设计基线为随机独立盐和 PBKDF2 HMAC SHA256，迭代 600,000 次，保存算法参数和校验结果；使用 Workers 原生 Web Crypto。这个参数参考 [OWASP 密码存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)，原生 API 能力参考 [Cloudflare Web Crypto](https://developers.cloudflare.com/workers/runtime-apis/web-crypto/)。输入密码只在处理请求时使用，不进入日志，也不保存明文。

此密码基线尚未验证能否满足 Workers 免费版单次请求的 CPU 预算。实施计划必须先验证实际远端运行的初始化、登录和修改密码，记录延迟、CPU 用量及资源超限情况。未通过时需重新评审登录计算方式与部署成本，不能通过降低密码保护参数来声称已经支持免费方案，也不能自动启用付费套餐。

成功登录后签发随机会话令牌，使用 Secure、HttpOnly 和 SameSite Cookie；数据库保存会话令牌摘要、期限和会话代数。所有资料 API，包括 PDF 分段读取、图片、附件和历史内容，都检查有效会话。写入操作校验来源并限制请求大小，登录和初始化提供失败频率限制。Markdown 渲染、文件响应和会话校验共同防止笔记内容绕过登录保护。

修改密码要求提供当前密码和新密码，成功后使所有会话失效并回到登录页。退出所有设备使当前设备和其他设备的会话统一失效；其他页面在下一次请求或重新获得焦点检查会话时返回登录页。已经展示过的内容不能从用户已经取得的副本中撤回。

忘记密码通过具有 Cloudflare 部署权限的管理命令重置：先撤销全部会话，再生成新的单次设置链接。该流程保留 D1 中的笔记数据和 R2 中的文件，不提供可公开调用的免验证重置入口。这里的密码用于访问控制，资料不依赖该密码加密，因此重置密码不需要重建或删除笔记。

## 部署架构与数据职责

| 模块       | 对外职责                                 | 主要依赖                                |
| ---------- | ---------------------------------------- | --------------------------------------- |
| 响应式前端 | 导航、阅读、编辑状态、草稿和文件预览     | 资料 API；按需加载的编辑器和 PDF 查看器 |
| 访问控制   | 初始化、密码校验、会话和部署端重置       | D1、Worker Secrets、Web Crypto          |
| 笔记服务   | 节点树、稳定链接、正文保存和并发版本检查 | D1、文件存储接口                        |
| 文件存储   | 私有对象读写、分段读取、引用和空间统计   | R2、D1 中的对象登记与容量预留           |
| 恢复服务   | 回收站、正文版本保留、恢复和垃圾清理     | 笔记服务、文件存储                      |
| 阅读记录   | 收藏、最近访问、跨设备阅读位置           | D1                                      |

Worker 与前端静态资源一起部署。前端通过同源 API 访问服务，R2 保持私有。静态应用资源可以缓存；私人正文和文件不放入绕过登录校验的公共缓存。第一版不提供离线资料库。

D1 保存单例站点设置、密码校验参数、会话、节点关系、正文版本指针、对象引用、回收站批次、收藏、阅读位置以及用量登记。R2 保存不可变的正文对象和上传文件。正文在 D1 中只保留索引信息及对象标识，避免把长正文和二进制文件放入单条数据库记录。D1 当前单行上限为 2 MB，免费版单库上限为 500 MB，参见 [D1 限制](https://developers.cloudflare.com/d1/platform/limits/)。

每次保存先登记操作与容量预留，再写入新的不可变 R2 对象，最后在 D1 内原子更新当前版本、历史引用和用量。只有最后一步成功才向用户报告保存成功。提交携带开始编辑时的版本号；版本过期、权限失效或容量不足都不能覆盖当前内容。条件更新未命中必须作为提交失败处理，不能把零行更新误认为整批事务失败。

D1 的批处理可为数据库内操作提供事务，但不能把它与 R2 写入视为同一事务；其行为参考 [D1 batch 文档](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)。跨存储失败依靠持久化操作记录、幂等重试和后台清理收敛：已上传但未引用的对象登记为待清理，当前已生效的对象在有引用时始终保留。实际清理先在 D1 中原子检查引用和操作状态，将可回收对象标为正在删除并禁止新增引用，再删除 R2 对象；确认删除后才释放应用的字节登记。不能使用没有并发保护的“先查引用，再删文件”流程。

回收站到期和无引用对象由一个定时清理任务小批量处理。清理失败保留状态并重试，不把“数据库已标记删除”当成“对象已释放空间”。任何内容更新失败都保留旧的已保存版本；客户端失败时保留当前输入并提供重试。

## 免费额度与运行边界

以下是 2026 年 10 月 1 日核对官方文档后的平台信息，平台可能调整，部署前需要再次核对。

| 服务           | 当前相关额度                                                  | 本项目的设计措施                                                   |
| -------------- | ------------------------------------------------------------- | ------------------------------------------------------------------ |
| Workers 免费版 | 每天 100,000 次请求，单次请求 10 ms CPU                       | 客户端渲染、编辑器按需加载、合并资料元数据请求，先验证密码相关操作 |
| D1 免费版      | 每天读取 500 万行、写入 10 万行，单库最多 500 MB              | 保存结构化信息，使用索引和分页，阅读位置节流更新                   |
| R2 标准存储    | 每月包含 10 GB-month、100 万次 A 类操作和 1,000 万次 B 类操作 | 不可变对象复用，有限正文历史，回收站定期清理，容量预留与上限       |

额度来源为 [Workers 限制](https://developers.cloudflare.com/workers/platform/limits/)、[D1 计费](https://developers.cloudflare.com/d1/platform/pricing/)、[D1 限制](https://developers.cloudflare.com/d1/platform/limits/) 和 [R2 计费](https://developers.cloudflare.com/r2/pricing/)。

8 GB 内容上限是应用建议值，不是费用封顶承诺。Cloudflare 账号中的其他项目也会消耗共享额度；R2 按存储时间与操作次数计费，删除文件不抹去之前已经发生的用量。R2 需要开通订阅，即使实际使用落在免费额度内，参见 [R2 开通说明](https://developers.cloudflare.com/r2/get-started/)。

接近上限时显示当前内容、历史版本、回收站和等待清理的占用。达到上限后继续允许阅读、收藏、阅读进度记录、删除和清理；新增正文版本、上传或其他增加实际占用的动作先检查容量。释放空间经确认后才能重新使用，避免多个设备同时上传越过上限。

## 验收要求

1. 未初始化时只能通过有效的专属链接设置密码；初始化并发只有一次成功。未登录请求不能读取节点、正文、历史、图片、PDF 分段或附件。
2. 登录、刷新、新打开的标签页以及保存后均符合阅读状态表；默认页面只有预览，电脑源码分栏不会提前出现。收藏、最近访问、目录跳转、图片放大和进度记录可以在只读模式下使用。
3. 树支持笔记下挂笔记和文件节点；禁止循环移动。重命名和移动不会破坏内部链接；外链通过新标签页打开。
4. Markdown 和纯文本可以手动保存；PDF、图片可作为节点或附件查看。同一个附件另建节点不重复计费，也不会因删除其中一个引用而损坏另一个引用。
5. 删除子树可整体恢复；单独删除的后代保留其原有到期时间。过期或永久删除后无法恢复，后台仅删除无引用对象，空间统计与真实对象状态一致。
6. 每篇最多保留 5 个历史版本和当前版本；无变化保存不增加历史。恢复旧版本形成新当前版本，当前内容与版本引用都正确保留。
7. 电脑和手机可以接续 Markdown 位置和 PDF 页码；内容变化后恢复位置仍在有效范围内。后台页和旧同步请求不覆盖当前阅读状态。
8. 收藏不复制内容；最近访问最多展示 20 个不同节点；删除、恢复和永久删除后的快捷入口行为正确。
9. 修改密码、退出所有设备和部署端重置都撤销旧会话；部署端重置后原笔记、附件、回收站和历史仍可在重新登录后访问。
10. 两个设备从同一正文版本保存时，只接受一个基于该版本的更新；另一个保留输入并显示冲突。数据库提交失败、上传中断、重复请求和清理失败不会损坏已保存内容或重复计算空间。
11. 验证电脑和实际手机尺寸下的预览、两级解锁、源码切换、标题目录、图片缩放与 PDF 阅读；关闭图片查看和目录面板能正确返回阅读位置。
12. 在获得部署授权后的免费远端环境验证密码流程、普通阅读、正文保存、文件传输与清理任务的实际 CPU 和用量。验收记录明确哪些操作已满足免费方案限制，不能以本地通过代替远端验证。
