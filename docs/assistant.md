# 青藜与翻译

## 配置与思考深度

在「设置 → 青藜」填写 DeepSeek API Key，可先测试连接再保存。单次回复上限默认 **8192 tokens**，可选择 2048、4096、8192、16384 或 32768；已有 Key 时可单独修改长度。

模型使用支持文字和图片的 `deepseek-flash`，参见[官方图片输入文档](https://api-docs.deepseek.com/guides/vision/)。DeepSeek 调用使用该账户的额度，与 Cloudflare 免费额度分开；连接测试仅查询模型列表，不生成回复。

思考深度可选关闭、低、高、最高，默认关闭，作用于文件内和全局青藜会话。已有 Key 时可单独修改深度；深度越高，通常等待越久、消耗越多。思考与回答共用单次回复上限，若思考耗尽额度而尚未生成回答，会提示提高上限或降低深度。返回的思考过程默认折叠，可点击「查看思考过程」展开，生成时也可查看，随会话保存并计入空间；旧回复不会补生成思考内容。复制回复、保存为笔记及后续提问只使用正式回答。

## 打开会话与引用原文

打开文件后点击右下角的「青藜」或工具栏的助手图标。标题栏可切换三种模式：悬浮窗口支持鼠标或触摸拖动，也可聚焦标题后用方向键移动；贴边固定在阅读区右侧，宽屏下与正文并排；最大化占满页面，再次点击还原到之前的模式。收起后保留悬浮入口，同一文件的草稿、待发送附件和会话会保留。`Esc` 先还原最大化窗口，普通窗口下收起青藜。

首页、收藏、设置等页面有全局青藜入口，文件对话里也可切换过去。全局对话独立保存，使用同一套 DeepSeek 配置，回复可保存为根目录笔记，也可主动附上正在阅读的文件。

在正文、PDF（含附件）或聊天中选中文字，会弹出「复制 / 问青藜 / 翻译」工具条。「问青藜」打开当前文件的助手并填入引用，保留问题草稿，点击发送后才提交；公式引用保留 LaTeX。点击空白处、滚动或按 `Esc` 收起工具条；也可以继续使用助手里的「引用选中文字」。

输入区的「本次参考」显示当前问题将附上的全文、章节、PDF 页码、选文、批注和截图；普通文件对话仅绑定会话，不会自动附上正文，书籍上下文会单独标明。历史对话中已发送的材料仍可能被参考。从正文加入的选文和当前文件附件会保存来源，可在发送前或重开会话后点击「返回原文」；选文定位到对应文字，PDF 选文和附件返回所选页码。引用内容保持发送时的快照，原文件后来修改不会改变已发送的材料。

## 截图与文件附件

「框选截图」会暂时隐藏助手并截取当前阅读区，在电脑或手机上拖动框选、预览，点击发送后才提交给 DeepSeek。PDF 截图直接合成已渲染画布，Markdown/纯文本/图片页面通过浏览器内渲染截图，无需安装扩展或屏幕共享。外部站点图片无法可靠读取像素时会提示先上传到笔记；链接所指向的外部页面不会自动读取。

「附上当前文件」读取当前内容，「另选文件」从电脑或手机选择文件。文件先在浏览器解析、预览，附到待发送列表后仍可移除；只有发送时才上传并交给 AI。普通 PDF 默认提取文字并保留页码，无文字或文字极少的页面自动转图；图表、公式和复杂排版可选「整页图片」。可填写 `1-5,8,10-12` 选择页码，每次最多处理 200 页；超过限制会提示缩小范围，不静默截断。DeepSeek 接收解析后的文字和页面图片，原 PDF 保存在私有存储供下载，不直接传给模型；[官方文件接口](https://api-docs.deepseek.com/api/create-file/)用于图片输入。

每次最多 3 个文件，文件图片合计最多 6 张（每张最多 1 MiB）。附件文字按 tokens 检查，不设固定字符数上限。原文件最多 50 MB，聊天 Markdown / TXT 附件最多 8 MiB，支持 UTF-8 和带 BOM 的 UTF-16；聊天请求及单条消息存储另有 16 MiB 的数据大小保护，普通笔记正文仍最多 1 MiB。图片压缩后发送，动图使用一帧。普通链接节点仅附上标题和网址；已导入的 arXiv 论文可附上保存的正文。

## 划词翻译

「翻译」直接打开浮窗，默认只显示译文和展开按钮，高度随内容变化，长译文可滚动。展开后可查看原文、切换语言、复制、重新翻译、问青藜，以及拖动、固定、最大化窗口；收起和展开保留译文，不重新调用 AI。复用设置中的 DeepSeek Key，自动识别源语言，默认译为简体中文，可切换目标语言并在当前浏览器记住选择。每次最多 10,000 字符，只发送所选原文，不发送全文、定位前后文或聊天历史；使用非思考模式，译文上限 8192 tokens，5 分钟超时。关闭窗口或切换任务会停止未完成的请求。

完整译文自动保存到所属文件，点击文件工具栏的「翻译记录」可再次查看，刷新、换设备后仍保留。相同文件、原文和目标语言复用已保存结果，不重复调用模型；「重译」主动请求新结果，失败或中断时保留旧译文，不保存不完整结果、不自动重试。记录可单独删除；原文、译文和位置信息保存在私有 R2 并计入空间，随文件进入回收站、恢复和永久清理。

正文翻译保存选区偏移、原文和前后文；从记录点击「回到原文」会定位并高亮，正文修改后尝试重新匹配，原文丢失或匹配不唯一时明确提示。PDF 保存文件 ID、页码和相对选区坐标，缩放后仍可定位，附件 PDF 会自动重新打开；附件已移除时提示无法定位。缓存保留首次保存的原文位置，聊天中的选文不记录正文位置。

## 上下文与续写

只发送主动提交的提问、附件、引用、截图以及本文件最近的会话，不自动提交全文。问题最多 8,000 字符，引用最多 20,000 字符，截图最多 1 MiB；上下文最多携带 20 条已结束的消息（含当前问题、有内容的中断回复）及 8 张图片。使用当前 `deepseek-flash` 的 [1,048,576 tokens 上下文容量](https://api-docs.deepseek.com/zh-cn/api/list-models/)，统一计算系统提示、问题、引用、附件、图片与历史，预留所配置的回复长度（默认 8192）、1024 tokens 协议余量，并在估算输入上增加 20% 余量。文字按[官方换算指引](https://api-docs.deepseek.com/zh-cn/quick_start/token_usage/)估算，符号和非常用 Unicode 更保守；图片按[每张最多 1024 tokens](https://api-docs.deepseek.com/zh-cn/guides/vision/)计入。这是估算而非精确分词，实际用量以 DeepSeek 为准。

容量不足时优先省略较早的完整对话轮次，并在助手中提示，完整历史仍保留。如果本次内容本身超出预算，在创建消息和调用 AI 前拒绝，显示估算用量与可用预算，输入及附件保留供调整；附件不静默截断。若提供方按实际分词拒绝，明确提示上下文超限，已提交内容保留在历史中，不自动重试付费请求。旧会话仍可分批查看；长附件历史按数据量缩小分页，单条内容完整返回，避免一次加载过多。默认生成超时为 5 分钟，16384 / 32768 tokens 分别延长至 10 / 20 分钟。

截断、手动停止或连接中断后，已收到并保存的回复可点击「继续生成」；续写会带上所选回复和原问题，沿用原引用与附件，不提交或清空输入框里的草稿。多次续写沿原分支追溯，原问题与续写内容一起检查预算；无法完整放入时提示重新提问，不丢弃必要的原文，也不绕过模型容量、20 条消息或 8 张图片限制。续写作为新回复保存在同一会话中，失败不会自动重试付费调用。完整或中断的非空回复均可一键保存为当前文件下的 Markdown 子笔记，已保存的笔记保留原内容。设置、聊天、保存回复为子笔记及整理目录可直接操作，无需进入编辑模式；删除内容、清空会话等操作保留各自的确认。

## 数据保存

会话正文、附件原件及处理后的图片存在私有 R2，计入全库空间；文字按发送时的内容保存快照。随源文件进入回收站时保留，清空会话或永久删除源文件后由清理流程回收；其他笔记仍在使用的共享原文件不受影响，已生成的 Markdown 是独立子笔记。取消或失败留下的未引用上传由既有草稿清理机制回收。

API Key 由 `APP_SECRET` 派生 AES-GCM 密钥加密后存入 D1，浏览器仅收到配置状态；轮换 `APP_SECRET` 后需要重新保存 AI Key，修改登录密码无需重新配置。

自动测试使用模拟 DeepSeek 响应；真实 API 联调需配置自己的有效 Key。
