# 青藜与翻译

## 配置

在「设置 → 青藜」填写自己的 DeepSeek API Key，可先测试连接。测试只查询模型列表，不生成回复。模型为 `deepseek-flash`，支持文字和图片。

单次回复默认 8192 tokens，可选 2048、4096、8192、16384、32768。思考深度可选关闭、低、高、最高，默认关闭。思考和回答共用回复上限；深度越高，通常等待越久、消耗越多。思考过程默认折叠并随会话保存，复制、存为笔记和后续提问只使用正式回答。

## 会话与引用

文件中的青藜按文件保存对话。首页、收藏和设置中的全局青藜单独保存。桌面窗口可拖动、停靠或最大化；Esc 先退出最大化，再收起窗口。收起后保留草稿与待发送附件。

选中文字后点「问青藜」，会把选文放进输入区，点击发送才提交。公式保留 LaTeX。也可框选阅读区截图，或附上当前文件、章节和其他文件。

「本次参考」列出当前提问附带的材料，普通文件对话不会自动附上正文；书籍会另带书籍上下文。历史中已发送的材料仍可能被参考。选文和文件附件可「返回原文」，PDF 可返回页码；引用保留发送时的快照。

## 附件与限制

文件先在设备上解析和预览，发送时才上传。PDF 默认提取文字，无文字或文字很少的页面转为图片；也可选整页图片。页码可写成 `1-5,8,10-12`，每次最多 200 页。原 PDF 留在私有存储供下载，模型收到文字和页面图片。

| 内容 | 上限 |
| --- | --- |
| 问题 / 引用 | 8000 / 20000 字符 |
| 附件 | 每次 3 个文件 |
| 文件图片 | 合计 6 张，每张 1 MiB |
| 截图 | 1 MiB |
| 原文件 | 50 MB；Markdown / TXT 为 8 MiB |
| 请求及单条消息存储 | 16 MiB |
| 上下文 | 最多 20 条消息、8 张图片 |

Markdown / TXT 支持 UTF-8 和带 BOM 的 UTF-16。图片压缩后发送，动图取一帧。普通链接只附标题与网址，不读取外部页面；外链图片无法截图时需先上传到笔记。

## 长对话与续写

按 1,048,576 tokens 的上下文容量估算系统提示、提问、引用、附件、图片和历史，并预留回复长度、1024 tokens 协议余量及 20% 输入余量。文字和图片的估算方法见 DeepSeek 的[用量说明](https://api-docs.deepseek.com/zh-cn/quick_start/token_usage/)与[图片说明](https://api-docs.deepseek.com/zh-cn/guides/vision/)，实际用量以提供方为准。

超限时先省略较早的完整对话轮次，并提示；本次内容仍放不下时拒绝发送，保留输入与附件。提供方拒绝或连接中断后不会自动重试付费请求。生成超时默认 5 分钟，16384 / 32768 tokens 分别为 10 / 20 分钟。

中断、停止或截断的非空回复可「继续生成」，沿用原问题、引用和附件，不提交输入框草稿。续写仍检查容量并作为新回复保存。回复可存为独立 Markdown 子笔记。

## 划词翻译

选文字点「翻译」，默认译为简体中文，可切换语言。每次最多 10000 字符，只发送所选原文；不使用思考，译文上限 8192 tokens，5 分钟超时。

完整结果自动保存到文件的翻译记录。同一文件、原文和语言复用已有结果；「重译」会重新计费，失败时保留旧结果。关闭窗口或切换任务会停止未完成的请求。

记录可回到正文或 PDF 原文。正文修改后会重新匹配，原文丢失或位置不唯一时提示；聊天选文不记录正文位置。

## 数据保存

会话、附件和翻译存在私有 R2，计入空间。永久删除源文件或清空会话后由清理任务回收，已存为笔记的回复独立保留。

API Key 用 `APP_SECRET` 派生的密钥加密后存入 D1，浏览器只收到配置状态。轮换 `APP_SECRET` 后需重新保存 Key，修改登录密码不影响它。加密资料的处理范围见[本地加密](encryption.md#由服务器处理的功能)。
