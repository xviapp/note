# 搜索

按 Ctrl/Cmd+K 或 / 打开搜索，手机点顶部或侧栏的搜索按钮。搜索标题、正文和批注；多个词用空格分隔，每个词都要匹配，英文不区分大小写。

默认按相关度排序，依次优先匹配完整标题、标题关键词、正文和批注，同类结果按最近修改排列。可改为「最近更新」，最多显示 30 项。

「范围」可选全部笔记或当前目录及下级；打开文件时指其上级目录。「类型」可筛选笔记、文件夹、论文、书籍、PDF、图片、网页链接、日记本和项目。未输入关键词时显示最近访问。

## 正文范围

只搜索 Markdown 和纯文本的当前正文。论文、PDF、图片、书页识别文字、翻译和青藜对话不在正文搜索范围内；回收站内容和读书讨论不显示。结果显示命中片段，打开后定位并高亮。

未加密正文去掉 Markdown 标记后写入 `note_text`，用 FTS5 trigram 索引。三个字及以上的词走索引，短词逐篇匹配。保存时更新索引；旧笔记、恢复的备份和取消加密的笔记后台补建。正文暂时读不到时先不计入索引，稍后按 30 分钟起逐次加倍的间隔重试，8 次仍失败才按空正文处理。索引不进入备份。

## 加密与离线

加密正文不进服务器索引。设置加密或移入加密目录时，删除相应索引；明确设为不加密的下级稍后补建。补建写入前会再次确认正文仍为当前版本、仍未加密，且仍是读取时的那份文件，读取后才加密的正文不会写回。

本机可搜索已缓存且已解锁的加密正文，结果标注「本机」，使用相同的筛选与排序。解密文字只留在页面内存中，锁定后清除。服务器不可用时保留本机结果。
