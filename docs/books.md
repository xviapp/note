# 书籍与书页

在「新建 → 书籍」填写书名、作者、页数和青藜角色。打开书籍后，点击「书籍资料」或「⋯ → 书籍资料」，可以直接修改书名，保存后同步更新目录中的条目名称。

书籍资料支持上传、预览、更换和移除封面。图片保存时自动压缩，封面显示在书籍资料卡中，与书籍一同参与备份、加密及离线保存。移除封面不会删除书页或读书笔记。

通过「手动添加页面」输入正文，或用「拍照添加页面」识别书页。页面按页码排列；阅读任意书页时，点击「书内目录」即可查看已添加的页面，识别当前页并跳转到其他书页，也可返回书籍。目录只列出已添加的书页，不会根据书名生成未录入的章节。

本页摘要中的「值得追问」采用读者向青藜提问的口吻，围绕原文中的知识和论证展开。点击旧的阅读偏好提示时，也会请青藜解释和比较其中的知识点。手动输入的问题保持原样发送。

书页与其他文件使用相同的青藜悬浮入口和窗口，桌面默认悬浮，可手动停靠或最大化；手机使用底部浮层。点击追问、打开讨论或划词提问时，不会强制改变窗口模式。

每页可以有多个讨论。讨论带上书名、青藜角色、本页原文与摘要；在青藜中点击「整理到笔记」，可将结论与依据追加到本页读书笔记，书籍页支持汇总各页的读书笔记。
