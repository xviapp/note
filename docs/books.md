# 书籍与书页

新建书籍，填写书名、作者、页数和青藜角色。「书籍资料」中可改名、换封面或修改这些信息。封面随书籍备份、加密和离线保存。

## 添加书页

可手动输入正文，或拍照识别。手机拍照后可移除照片、继续拍下一页，再一起识别；也可从相册多选。电脑上选择图片文件。

书页按页码排列。「书内目录」列出已添加的书页，可跳页或返回书籍。

## 讨论与读书笔记

点击「值得追问」、划词「问青藜」，或在书页底部提问。Enter 发送，Shift+Enter 换行。未发送的问题保存在本机，加密书籍的草稿也加密。

每页可有多个讨论，青藜会参考书名、角色、本页原文和摘要。「整理到笔记」把结论与依据写入本页读书笔记，书籍页可汇总各页笔记。手动改过的整理内容不会直接覆盖。

书籍首页的对话参考书名、作者、角色、已录入书页的标题与摘要，以及读书笔记。需要原文细节时，到对应书页提问。回复可保存为书籍下的笔记。
