# 书籍与书页

在「新建 → 更多类型 → 书籍」填写书名、作者、页数和青藜角色。打开书籍后，点击「书籍资料」或「⋯ → 书籍资料」，可以直接修改书名，保存后同步更新目录中的条目名称。

书籍资料支持上传、预览、更换和移除封面。图片保存时自动压缩，封面显示在书籍资料卡中，与书籍一同参与备份、加密及离线保存。移除封面不会删除书页或读书笔记。

通过「手动添加页面」输入正文，或用「拍照添加页面」识别书页。手机上「拍照添加页面」直接打开后置相机，拍完可在识别窗口中查看缩略图、移除拍坏的照片，或点「继续拍下一页」连续拍摄，最后统一识别；「从相册添加」可一次选择多张已有照片。电脑上选择图片文件。页面按页码排列；阅读任意书页时，点击「书内目录」即可查看已添加的页面，识别当前页并跳转到其他书页，也可返回书籍。目录只列出已添加的书页，不会根据书名生成未录入的章节。

点击摘要下的「值得追问」、划词「问青藜」或在书页底部输入问题，都可开始本页讨论。

青藜在桌面支持悬浮、停靠和最大化，手机使用底部浮层。

每页可以有多个讨论。讨论带上书名、青藜角色、本页原文与摘要；在青藜中点击「整理到笔记」，可将结论与依据追加到本页读书笔记，书籍页支持汇总各页的读书笔记。

书页底部输入问题后，Enter 提问，Shift+Enter 换行。未发送的问题按书页保存在本设备，加密书籍的草稿同样加密；提问后新建讨论并打开青藜。

书籍首页也有青藜入口，用于谈论整本书：对话带上书名、作者、青藜角色、已录入各页的标题与摘要，以及书籍的读书笔记；不带各页原文，需要细节时请到对应书页提问。这段对话保存在书籍上，回复可保存为书籍下的笔记。
