新增
- 普通 Markdown 默认开启快捷编辑，直接追加文字和照片，按章节修改或删除内容，可按篇关闭并记住选择。章节修改支持本机草稿恢复、版本历史和保存冲突保护。
- 手机编辑源码时，键盘上方显示格式栏：标题、加粗、斜体、列表、待办、引用、代码、链接、缩进和插入随手记，撤销和重做固定在右端。
- Android 可用指纹解锁加密笔记。用密码解锁后可选择交给系统密钥库保管；修改密码、录入新指纹、全部锁定或退出登录后需重新用密码解锁。
- Android 应用锁的 PIN 改用数字键盘输入。
- 任意条目都可设置自定义图标；点标题旁的笔可直接重命名。
- 电脑上按住 Ctrl 或 Shift 可多选笔记，一起移动或删除。
- 电脑网页版可导入 Markdown 笔记库文件夹，保留图片和笔记间链接。

优化
- 选文工具栏保持单行，常用操作直接显示；其余收进「更多」纵向菜单，键盘可逐项操作。
- 手机上弹窗、编辑工具栏、回收站和设置中的按钮统一为标准点击高度，代码块、表格和提示文字更易读。
- 网页版首次打开的下载量减少约三成：中文阅读字体、设置、导入和随手记改为用到时加载。
- Android 安装包缩小约 43%，保留原有中文字体、公式显示和离线阅读能力。
- Android 新安装默认连接 iyi.li；已安装且未改过服务器的继续使用 note.iyi.li。

修复
- 青藜回复中用 \(…\) 和 \[…\] 书写的公式正常显示。
- Android 阅读选文不再重复显示系统菜单，保留选区手柄；关闭工具栏或滚动后，仍保留的选区改用系统菜单。
- 加密笔记不再与其他笔记共用同一份附件，备份仍引用的文件不会被提前清理。
- 笔记加密状态变化后搜索索引重新检查，暂时读不到的正文稍后重试。
- 书页识别不会因重复提交而重复计费。
- 保存过程中继续写下的内容作为单独一次保存发送，不再被上一次保存吞掉。
- 随手记无法保存到本机时给出提示。
- 「立即锁定」后菜单自动收起。
