# 随手记

保存文字、链接或图片，不进入目录树。按时间倒序排列，置顶在前。

## 打开方式

- 顶栏便签按钮，或电脑按 Q。
- 编辑工具栏的「插入随手记」，手机在「更多编辑操作」中。
- 阅读选文后点「更多 → 记一下」，附上当前文件来源。
- Android 长按图标、桌面「页间快捷栏」或文字选择菜单。
- Android 分享文字、链接或单张图片时点「存入随手记」。

## 保存与整理

写好后点「保存」或按 Ctrl/Cmd+Enter，回车换行。从文件打开时可勾选「附上来源」，点击来源返回文件；文件删除或进回收站后隐藏来源标题。

未提交文字暂存在本机，关闭或刷新后可继续；图片需重新选择。保存、清空文字或退出登录后清除草稿，加密随手记的草稿也加密。

每条最多 10000 字，可带一张 PNG、JPEG、GIF、WebP 或 AVIF 图片，上限 10 MB，也可粘贴截图。图片可单独保存。点正文可选择文字，操作区按钮用于复制；长内容可展开，点图片放大。复制图片不受系统支持时可下载。

编辑笔记时可「插入到正文」，文字插到光标处，图片重新上传为该笔记附件。插入不会自动归档。「转为笔记」可改标题和目录，完成后移除原随手记；加密内容转到未加密目录前会提示。

## 置顶与归档

最多置顶 50 条。未归档、未置顶的最多保留 500 条，超出的旧条目由定期清理删除。列表每次加载 50 条，筛选只查已加载内容。

归档会取消置顶并移出主列表。右上角进入「已归档」，可搜索、恢复、复制、插入或转为笔记。归档内容和图片长期保留，搜索会读取后续分页；加密内容需解锁。删除、归档后短时间内可撤销。

## 离线与待发送

文字先存本机，联网后发送，重试不会重复。明确被拒绝的条目保留原因，可在「设置 → 待发送」重试或删除。带图片的条目需要联网。

打开过的最近列表和归档首页可离线浏览、复制。置顶、归档、恢复、删除、转为笔记和加密设置需联网。退出登录清除本机缓存与未发送内容。

Android 快捷输入窗口只收文字，保存后先加密写入本机，再关闭并后台上传；未登录或需要内容密钥时留待打开应用后处理。点关闭不保存，点窗口外不关闭。记录按服务器隔离，不会发到另一个站点。

## 加密与备份

标题栏锁按钮可设置或修改密码。新旧条目、图片和归档内容都在设备上加密；中断后用「检查并同步」完成。修改密码只重新包装密钥，取消加密会解密后上传。

主面板解锁后才能查看和新增。忘记密码无法恢复，见[本地加密](encryption.md)。

整库备份包含随手记、归档状态和图片；恢复保留条目标识，同库不重复，来源和图片指向恢复出的副本。
