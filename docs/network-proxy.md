# Android 网络代理

在「设置 → 服务器 → 网络代理」填写已有代理的 SOCKS5 或 HTTP 端口，只对页间生效。应用不含代理核心，不改系统代理，不需要 VPN 权限。

## 设置

地址格式为 `socks5://主机:端口` 或 `http://主机:端口`，只写主机和端口按 SOCKS5 处理。支持 `socks://`、`socks5h://` 别名，不支持认证和 `https://` 代理。SOCKS5 由代理解析域名。

填写地址后开启「使用代理」。可选「连接 VPN 时直连」：页间默认网络经过 VPN 时暂停代理检测、直接联网，VPN 断开后恢复。设置只保存在本机。

## 检测与回退

需要联网时检测代理，不定时轮询。打开代理、改地址、切换 VPN 选项、点「检测」、网络变化、回到前台或请求失败时重新检测。

检测确认代理本身可连接，不保证能访问外网。SOCKS5 要求无认证握手成功，HTTP 只检查端口。连接超时 1.5 秒、读取超时 1 秒；成功结果复用 60 秒，失败结果复用 15 秒。

代理可用时，WebView 和原生请求走代理；本机及局域网地址直连。代理不可用时自动直连，并在页面显示警告；恢复后自动切回。代理断开不会阻止联网，流量会直接发出。

代理断开造成的 GET 请求可直连重试一次，普通写请求由用户重试。原生下载和带幂等标识的随手记上传也可重试一次。

## 实现与测试

`NoteProxyNetwork` 负责线路和检测，`ProxyAddress`、`ProxyProbe` 负责解析与探测，`src/proxy.ts` 处理前端状态。WebView 代理在页面准备后设置，不能提前到 `onCreate`，否则包内资源可能停顿。

```bash
node scripts/android.mjs testDebugUnitTest
```
