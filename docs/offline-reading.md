# 阅读设置与本机缓存

阅读页的 Aa 和设置页共用阅读选项。系统字体、Noto Serif SC 宋体、Noto Sans SC 黑体，以及字号、行距、字间距、段落间距、正文宽度仅保存到当前设备；支持紧凑、舒适、宽松预设及恢复默认。字体随 Web 资源和 Android 安装包提供，无需访问第三方字体服务，许可证随资源发布于 `/licenses/`。

排版选项作用于 Markdown、纯文本和已导入的 arXiv 正文；公式、代码使用各自字体与字距。PDF 保持原版排版，通过现有缩放与适应宽度阅读。调整排版及目录宽度时保留章节阅读位置。

## 使用方式

- 在线打开文件后自动缓存正文、上传图片及附件，包括完整 PDF；侧栏「离线阅读」列出本机副本及下载状态。
- 文件菜单「离线保存」等待页面资源及文件全部准备好再标记成功。「取消离线保存」将副本转为普通自动缓存。
- 默认文件缓存上限 200 MB，设置中可调为 50、100、200、500、1000、2000 MB。超出容量时优先清理较久未读的自动副本；自动副本最多保留 100 份。手动保留的副本不自动清理；无法容纳时显示错误，不静默超限或移除已保留的文件。
- 「清理自动缓存」只清理本机自动副本，不删除云端，也不清理手动保留的文件。上限与用量统计针对正文及附件；目录快照另有 2 MB 上限，公共界面、字体、PDF 渲染资源独立缓存。
- 重新联网后验证登录状态，刷新当前阅读和手动保留的文件；旧文件 ID 不变时复用完整文件，不再次下载。云端明确返回删除、回收站或未登录时，不回退到旧私人副本。
- 支持断网重开和离线阅读位置记忆。编辑、青藜、翻译及其他服务端操作仍需联网。网页链接及外链图片不在离线保证范围内。
- 退出登录、修改密码或收到登录失效响应后清除私人副本、目录快照与阅读进度；其他打开的标签页同步失效。远端撤销会话需设备重新联网后才能获知。

## 存储边界

`src/offline-cache.ts` 使用 IndexedDB，按文件树节点保存正文和二进制附件的原子快照。只有完整文件响应通过大小检查后，手动离线保存才能完成；刷新下载中断时保留已有完整副本并显示未更新状态。容量检查和清理在同一事务中完成。任务代次阻止退出或清理前的异步请求重新写回；会话重置还会取消正在读取的文件。

只缓存白名单读取：登录成功标记（不含密码参数、口令或 Cookie）、存储概况、已访问目录、正文及关联文件。后端私人 API 继续使用 `no-store`；模型密钥、对话、翻译、历史版本以及写请求不会进入离线数据层。

文件夹图标按文件 ID 不可变，单独保存在 `icons` 存储中（每个不超过 128 KiB，最多 200 个，按保存时间淘汰），不计入文件缓存上限；加载过的图标在本次登录内常驻内存，返回列表或重开应用时直接显示、不再下载。「清理自动缓存」和退出登录会一并清除。目录列表在本次登录内保留在内存中：切换页面直接显示已加载的列表和分页，只在库内容变化、回到前台、重新联网或手动刷新时重新请求；「最近访问」每次进入在显示旧列表的同时后台更新。

公共界面资源由 `public/_headers` 设置缓存：带哈希的 `/assets/*` 长期不可变，青藜标识、应用图标、PDF 资源缓存一天并在后台更新。

`scripts/offline-shell.ts` 在 Web 构建时生成 `/sw.js`，只预缓存构建自有的公共界面、字体与 PDF 辅助资源，不拦截 `/api/`。使用 `/` 缓存页面入口，避免 Cloudflare 对 `/index.html` 的重定向导致 Chromium 离线导航失败。资源按构建版本更新，不强制接管仍打开的旧页面。Android 直接使用安装包中的资源，不注册 Service Worker。

首次安装将 WOFF2 字体和 PDF 字符映射合并为若干资源包下载，再恢复为原路径的缓存响应；跳过浏览器不会使用的 WOFF／TTF 回退文件，避免数百次小文件请求拖慢离线准备。每包约 2 MB 原始数据，资源内容参与版本摘要，更新未改名的公共文件也能刷新缓存。`npm run test:build` 检查二进制内容、路径还原、版本更新和 Android 构建隔离。

手动保存时申请浏览器持久存储；浏览器可能不批准，用户清理站点数据或卸载应用也会移除本机副本。[浏览器存储配额和清理规则](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)决定最终可用空间，本机缓存不是备份。

## 验证

`e2e/reading-offline.spec.ts` 覆盖电脑及手机下的排版即时生效／重载、数学与代码字距隔离、断网重开、图片和 PDF 附件／节点读取、PDF 进度、论文插图、重新联网更新、远端删除、跨标签页退出、容量清理及中断后保留完整副本。测试使用独立本地 Worker 和测试文件，不访问正式笔记或调用真实模型。

PDF 初次打开沿用流式阅读，由阅读器提供完整下载数据再缓存，避免重复请求或等待整份文件下载后才显示。测试还检查同一 PDF 不重复下载，以及成功状态码下的残缺登录响应不会误清理私人副本。
