# 阅读设置与本机缓存

## 阅读设置

电脑点 Aa，手机点「更多 → 阅读设置」，也可从设置页打开。字体、字号、行距、字距、段距和正文宽度保存在当前设备，可选紧凑、舒适、宽松预设。

排版适用于 Markdown、纯文本和 arXiv 正文；公式、代码使用各自字体，PDF 保持原版排版。字体随应用提供，无需外部字体服务，许可证位于 `/licenses/`。

Android 可开启屏幕常亮和音量键翻页。常亮默认开启，10 分钟无操作后恢复系统设置；翻页默认关闭，音量减翻下一屏、音量加翻上一屏，编辑时照常调音量。

列表显示摘要、下级数量和书籍进度。电脑网页版提供排序与紧凑显示，手机隐藏这行选项。摘要取自未加密正文索引；电脑侧栏保留树形顺序。

## 离线保存

打开文件后自动缓存正文、图片和附件。菜单中的「离线保存」会保留整份资料，所有资源准备好才标记成功；取消后转为普通自动缓存。「离线阅读」列出本机副本和下载状态。

| 项目 | 限制 |
| --- | --- |
| 文件缓存 | 默认 200 MB，可选 50、100、200、500、1000、2000 MB |
| 自动副本 | 最多 100 份，优先清理较久未读的 |
| 手动保留 | 不自动清理，空间不足时报错 |
| 目录快照 | 另计，上限 2 MB |
| 自定义图标 | 每个 128 KiB，最多 200 个，另计 |

「清理自动缓存」不影响云端或手动保留的文件。网页链接、外链图片不保证离线可用。离线可读高亮与批注，不能修改；编辑、青藜、翻译和其他服务端操作需联网。

登录过的设备先显示本机目录和笔记，同时向服务器验证、刷新。服务器确认正文前不开放编辑或恢复草稿。断网时保留副本；明确返回未登录、删除或回收站状态时，不回退到旧副本。重新联网后刷新当前文件和手动保留的资料。

退出登录、修改登录密码或登录失效时，清除私人缓存、目录、阅读进度、草稿和待发送内容，其他标签页也失效。远端撤销需联网后才能获知。清除站点数据或卸载应用也会移除本机资料，缓存不能代替备份。

## 草稿与同步

点击「编辑正文」或按 E 进入编辑。草稿成功写入本机后才显示「草稿已存本机」；暂存失败时保留编辑界面并提示原因。

点「保存」先回到预览，后台提交。Ctrl+S 保存后继续编辑。有未提交内容时，页面顶部显示待同步状态，可进入「设置 → 待发送」处理。只有成功暂存的草稿才进入后台提交；缺失草稿不发送，联网重试沿用同一操作标识。

服务器拒绝时保留草稿；仍在当前笔记上则回到编辑，离开后可从待发送打开处理。版本冲突可选「用我的版本覆盖」或「另存为新笔记」，覆盖前的服务器版本保留在历史中。

「待发送」右上角可看发送历史，只记录服务器确认成功的内容。本机保留最近 30 天、最多 500 条，退出登录清除；加密记录不保存明文摘要。

收藏、改名、移动、删除和新建先在界面显示结果，服务器拒绝时撤回并提示。搜索先显示本机结果，再用服务器结果替换，见[搜索](search.md)。

## 存储边界

- IndexedDB 按条目保存正文和附件快照；只有完整且大小正确的文件才标记下载成功。中断时保留已有完整副本，容量检查与清理在同一事务中完成。
- 清理、退出登录前启动的异步任务不能再写回；会话重置会取消文件读取。加密内容按服务器返回的密文缓存。
- 缓存白名单包括登录成功标记、存储概况、已访问目录、正文和文件、批注、随手记首页、全局青藜最新一页及配置状态。不存密码、Cookie、AI Key、文件内对话、翻译、历史版本或写请求。
- 空闲时预取列表里的文字笔记，每列表最多 20 篇，每次启动 60 篇。离线、省流量或缓存已满时停止；预取副本最先淘汰，打开后才补附件，不列入离线清单。
- Service Worker 只缓存公共界面、字体和 PDF 资源，不拦截 `/api/`；资源按构建版本更新，不强制接管旧页面。Android 使用包内资源，不注册 Service Worker。
- 目录在本次登录内复用，库内容变化、回到前台、联网或手动刷新时更新。PDF 初次打开沿用流式读取，完整下载后缓存，避免重复请求。

资源包由 `scripts/offline-shell.ts` 生成，`npm run test:build` 检查打包；`e2e/reading-offline.spec.ts` 检查断网、重连、容量、删除和跨标签页退出。
