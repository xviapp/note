# Markdown 快捷编辑

普通 Markdown 笔记可在「⋯」菜单中开启「快捷编辑」。开关按笔记保存在当前设备，关闭后恢复通常的阅读界面；「编辑正文」仍可打开全文编辑器。

开启后，底部可追加文字和照片，Ctrl/Cmd+Enter 保存。有标题时追加为二级标题，不附加时间；未填标题的内容接在文末，属于末尾已有章节。追加草稿和照片保存在本机，加密笔记的草稿也加密。

标题旁的「⋯」提供「编辑本节」和「删除本节」。章节从当前标题开始，到下一个同级或更高级标题之前，包含其中的子章节。代码块、引用和列表中的标题不单独划分章节。正文开头没有标题的内容作为「前言」。

编辑本节时，在原位置修改该节的 Markdown，包括标题和子章节；保存或取消后返回阅读。删除前会确认范围并提示子章节数量。每次修改和删除都会保存历史版本，可在「版本历史」中恢复。

章节编辑期间的修改会保存在本机，意外关闭后可通过全文编辑器恢复草稿。离开未保存的章节前会确认是否放弃。遇到版本冲突时保留输入，请复制修改内容，取消后重新打开；不会覆盖其他页面的新内容。保存结果尚未确认时须先重试，重试使用同一次保存请求。

快捷编辑需要联网并已解锁笔记。项目条目和日记继续使用各自的快捷记录入口，书页、讨论和论文不显示普通 Markdown 的快捷编辑开关。
