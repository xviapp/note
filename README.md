# 页间

适配电脑和手机的单人笔记应用，提供 Web 和 Android 客户端。首次通过专属链接设置一个密码，以后只用密码登录。打开笔记直接阅读，编辑器在确认后才加载。

## 已实现

- Aa 阅读设置：系统／宋体／黑体、字号、字间距、行距、段落间距、正文宽度；三档预设，按设备记忆，正文即时预览。
- 本机阅读缓存与手动离线保存：Markdown、TXT、导入论文、图片、完整 PDF 及附件，断网重开并恢复阅读进度；默认 200 MB，按容量清理自动副本，手动保存保留，联网检查更新，退出清除私人副本。详见[离线阅读](docs/offline-reading.md)。
- 树形目录；文件夹及各类文件均可包含下级笔记；支持新建未命名笔记、重命名、拖动、菜单移动与删除。文件夹可自定义 Emoji 或图片图标，图片自动缩为小图，可随备份恢复。
- 设置可指定系统分享的默认保存目录，网页和 Android 客户端共用；每次分享可临时更改，默认目录删除后回到根目录。
- Markdown 渲染、标题目录、任务列表、代码与表格；Markdown 与 arXiv 章节目录均位于右侧，可通过文件工具栏显示／隐藏，收放目录保留章节阅读位置；手机从右侧展开、选择章节后自动收起。内部链接使用稳定节点 ID；外部网页另开标签页。
- arXiv 论文导入：保存论文正文 HTML、公式和图片，直接在阅读区连续阅读；支持章节目录、引用跳转、图片放大、主题和阅读位置记忆。
- PDF 独占主阅读区，支持上下连续阅读、页码跳转、缩放与适应宽度，按可见范围渲染页面；工具栏右侧可显示／隐藏 PDF 内置目录，支持多级章节展开及书签定位，默认收起。电脑显示右侧目录栏，手机从右侧浮层展开、选择章节后自动收起；没有内置目录时显示提示。PDF 附件使用同一阅读器。PNG、JPEG、GIF、WebP、AVIF、SVG 图片放大及双指缩放；文件可作为节点或附件。同一附件另建文件节点时复用原文件。
- 文件默认只读；仅编辑正文、附件或恢复历史版本时确认，无全库编辑开关；电脑源码与预览并排，手机切换显示；手动保存、离开草稿提示、冲突保留草稿。
- 7 天回收站、当前版本加最近 5 个历史版本、收藏、最近 20 项访问记录。
- Markdown、纯文本及 PDF 阅读位置本地记录、最多每 30 秒云端同步；PDF 记忆页码与页内位置，缩放和调整窗口后接续阅读；切换笔记时补写，版本检查避免旧进度覆盖新进度。
- 文件页仅保留文件工具栏，手机的笔记树入口位于左侧；列表、收藏、回收站和设置页保留应用顶栏。
- 白天、夜间、星空和跟随系统主题；侧栏底部和设置中均可切换，当前设备记住选择，登录页、阅读区、编辑器和弹窗同步切换。
- 修改密码、退出当前设备或所有设备、部署端重置密码；新密码至少 8 个字符。
- 青藜（AI 助手）：每个文件独立会话，可附上当前文件或另选 Markdown、TXT、PDF、图片，引用选中文字或内置框选截图提问。PDF 支持选页提取文字、扫描页自动转图和整页图片。流式回复、停止生成、复制及保存为本文件下的 Markdown 子笔记。
- 全库默认 8 GB，上限可调，80% 用量提醒；历史、回收站、待清理文件和上传预留均计入空间。

普通笔记正文最多 1 MiB，单文件最多 50 MB。附件最多 100 个。超额时可以继续阅读、收藏、删除和清理。支持整库 ZIP 备份与恢复；全文搜索和离线编辑暂未提供。

## arXiv 论文

选择「新建 → arXiv 论文」，粘贴 `arxiv.org` 的 HTML、摘要或 PDF 链接，例如 `https://arxiv.org/html/2503.01800v1`。标题留空时自动使用论文标题。导入固定版本的正文、公式、图片和许可信息，去掉站点导航；源网页的脚本、样式和外部图片不会在阅读区加载。图片保存在私有 R2，正文与图片均计入空间，随论文进入回收站和清理流程。

论文直接显示在主阅读区，保留 MathML 公式、参考文献和内部引用跳转；可以整理目录、重命名及添加 Markdown 子笔记，论文正文保持只读。青藜支持引用选中文字和公式、框选截图，以及通过「附上当前文件」选择全文或章节。附给 AI 的公式转成 LaTeX；长论文也可选择全文，预览显示估算 tokens，发送时按模型上下文容量检查，不会静默截断。

每次导入 HTML 最多 8 MiB、24 张不同图片，单张最多 10 MiB、图片合计最多 50 MB。支持 PNG、JPEG、GIF、WebP、AVIF、SVG；无法识别的图片、下载失败或空间不足时，不创建不完整论文。没有 HTML 的论文仍可通过 PDF 文件阅读。导入请求最多等待 90 秒，失败后可手动重试。

SVG 文件和论文内嵌 SVG 均作为独立矢量图片保存，保留路径、文字、渐变、裁剪和图内引用；可放大、下载、截图及作为助手附件。存储前通过 XML 和 CSS 解析清理为静态图，移除脚本、事件、动画、外部资源引用及嵌入的 HTML；不加载外部 DTD，不展开自定义实体。普通 SVG 上传同样执行清理，上限 10 MiB。阅读时保留矢量图，发送给助手时由浏览器绘制成 JPEG，原 SVG 不直接交给模型。

## 青藜

在「设置 → 青藜」填写 DeepSeek API Key，可先测试连接再保存。单次回复上限默认 **8192 tokens**，可选择 2048、4096、8192、16384 或 32768；已有 Key 时可单独修改长度。模型使用支持文字和图片的 `deepseek-flash`；[官方图片输入文档](https://api-docs.deepseek.com/guides/vision/)。DeepSeek 调用使用该账户的额度，与 Cloudflare 免费额度分开；连接测试仅查询模型列表，不生成回复。

打开文件后点击右下角的「青藜」或工具栏的助手图标。标题栏可切换三种模式：悬浮窗口支持鼠标或触摸拖动，也可聚焦标题后用方向键移动；贴边固定在阅读区右侧，宽屏下与正文并排；最大化占满页面，再次点击还原到之前的模式。收起后保留悬浮入口，同一文件的草稿、待发送附件和会话会保留。`Esc` 先还原最大化窗口，普通窗口下收起青藜。

在正文、PDF（含附件）或聊天中选中文字，会弹出「复制 / 问青藜 / 翻译」工具条。「问青藜」打开当前文件的助手并填入引用，保留问题草稿，点击发送后才提交；公式引用保留 LaTeX。点击空白处、滚动或按 `Esc` 收起工具条；也可以继续使用助手里的「引用选中文字」。

「翻译」直接打开浮窗，默认只显示译文和展开按钮，高度随内容变化，长译文可滚动。展开后可查看原文、切换语言、复制、重新翻译、问青藜，以及拖动、固定、最大化窗口；收起和展开保留译文，不重新调用 AI。复用设置中的 DeepSeek Key，自动识别源语言，默认译为简体中文，可切换目标语言并在当前浏览器记住选择。每次最多 10,000 字符，只发送所选原文，不发送全文、定位前后文或聊天历史；使用非思考模式，译文上限 8192 tokens，5 分钟超时。关闭窗口或切换任务会停止未完成的请求。

完整译文自动保存到所属文件，点击文件工具栏的「翻译记录」可再次查看，刷新、换设备后仍保留。相同文件、原文和目标语言复用已保存结果，不重复调用模型；「重译」主动请求新结果，失败或中断时保留旧译文，不保存不完整结果、不自动重试。记录可单独删除；原文、译文和位置信息保存在私有 R2 并计入空间，随文件进入回收站、恢复和永久清理。

正文翻译保存选区偏移、原文和前后文；从记录点击「回到原文」会定位并高亮，正文修改后尝试重新匹配，原文丢失或匹配不唯一时明确提示。PDF 保存文件 ID、页码和相对选区坐标，缩放后仍可定位，附件 PDF 会自动重新打开；附件已移除时提示无法定位。缓存保留首次保存的原文位置，聊天中的选文不记录正文位置。

「框选截图」会暂时隐藏助手并截取当前阅读区，在电脑或手机上拖动框选、预览，点击发送后才提交给 DeepSeek。PDF 截图直接合成已渲染画布，Markdown/纯文本/图片页面通过浏览器内渲染截图，无需安装扩展或屏幕共享。外部站点图片无法可靠读取像素时会提示先上传到笔记；链接所指向的外部页面不会自动读取。

「附上当前文件」读取当前内容，「另选文件」从电脑或手机选择文件。文件先在浏览器解析、预览，附到待发送列表后仍可移除；只有发送时才上传并交给 AI。普通 PDF 默认提取文字并保留页码，无文字或文字极少的页面自动转图；图表、公式和复杂排版可选「整页图片」。可填写 `1-5,8,10-12` 选择页码，每次最多处理 200 页；超过限制会提示缩小范围，不静默截断。DeepSeek 接收解析后的文字和页面图片，原 PDF 保存在私有存储供下载，不直接传给模型；[官方文件接口](https://api-docs.deepseek.com/api/create-file/)用于图片输入。

每次最多 3 个文件，文件图片合计最多 6 张（每张最多 1 MiB）。附件文字按 tokens 检查，不设固定字符数上限。原文件最多 50 MB，聊天 Markdown / TXT 附件最多 8 MiB，支持 UTF-8 和带 BOM 的 UTF-16；聊天请求及单条消息存储另有 16 MiB 的数据大小保护，普通笔记正文仍最多 1 MiB。图片压缩后发送，动图使用一帧。普通链接节点仅附上标题和网址；已导入的 arXiv 论文可附上保存的正文。

只发送主动提交的提问、附件、引用、截图以及本文件最近的会话，不自动提交全文。问题最多 8,000 字符，引用最多 20,000 字符，截图最多 1 MiB；上下文最多携带 20 条已结束的消息（含当前问题、有内容的中断回复）及 8 张图片。使用当前 `deepseek-flash` 的 [1,048,576 tokens 上下文容量](https://api-docs.deepseek.com/zh-cn/api/list-models/)，统一计算系统提示、问题、引用、附件、图片与历史，预留所配置的回复长度（默认 8192）、1024 tokens 协议余量，并在估算输入上增加 20% 余量。文字按[官方换算指引](https://api-docs.deepseek.com/zh-cn/quick_start/token_usage/)估算，符号和非常用 Unicode 更保守；图片按[每张最多 1024 tokens](https://api-docs.deepseek.com/zh-cn/guides/vision/)计入。这是估算而非精确分词，实际用量以 DeepSeek 为准。

容量不足时优先省略较早的完整对话轮次，并在助手中提示，完整历史仍保留。如果本次内容本身超出预算，在创建消息和调用 AI 前拒绝，显示估算用量与可用预算，输入及附件保留供调整；附件不静默截断。若提供方按实际分词拒绝，明确提示上下文超限，已提交内容保留在历史中，不自动重试付费请求。旧会话仍可分批查看；长附件历史按数据量缩小分页，单条内容完整返回，避免一次加载过多。默认生成超时为 5 分钟，16384 / 32768 tokens 分别延长至 10 / 20 分钟。

截断、手动停止或连接中断后，已收到并保存的回复可点击「继续生成」；续写会带上所选回复和原问题，沿用原引用与附件，不提交或清空输入框里的草稿。多次续写沿原分支追溯，原问题与续写内容一起检查预算；无法完整放入时提示重新提问，不丢弃必要的原文，也不绕过模型容量、20 条消息或 8 张图片限制。续写作为新回复保存在同一会话中，失败不会自动重试付费调用。完整或中断的非空回复均可一键保存为当前文件下的 Markdown 子笔记，已保存的笔记保留原内容。设置、聊天、保存回复为子笔记及整理目录可直接操作，无需进入编辑模式；删除内容、清空会话等操作保留各自的确认。

会话正文、附件原件及处理后的图片存在私有 R2，计入全库空间；文字按发送时的内容保存快照。随源文件进入回收站时保留，清空会话或永久删除源文件后由清理流程回收；其他笔记仍在使用的共享原文件不受影响，已生成的 Markdown 是独立子笔记。取消或失败留下的未引用上传由既有草稿清理机制回收。API Key 由 `APP_SECRET` 派生 AES-GCM 密钥加密后存入 D1，浏览器仅收到配置状态；轮换 `APP_SECRET` 后需要重新保存 AI Key，修改登录密码无需重新配置。

`pnpm run deploy` 会先构建、应用生产数据库迁移，再部署新版；也可单独运行 `pnpm db:remote`。本地启动脚本自动应用迁移。自动测试使用模拟 DeepSeek 响应；真实 API 联调需配置自己的有效 Key。

## Android 客户端

Android 客户端使用 Capacitor，工程位于同一仓库的 `android/`，共用 React 界面与 Cloudflare 服务。安装后连接 `https://note.xvi.app`，用现有密码登录；笔记、阅读位置、翻译记录和青藜会话沿用同一份云端数据。0.2.0 支持阅读排版设置、自动缓存和手动离线保存；已缓存文件可以断网重开，编辑、翻译与青藜仍需联网。

需要 Android 8.0+，以及 Android System WebView 125+。旧网页组件会显示更新提示。支持系统文件选择与保存、外部链接交给浏览器、系统返回键收起窗口或目录、未保存修改的离开确认，以及应用切到后台时补写阅读进度。

本机构建需要 Node.js 22.12+、JDK 21、Android SDK Platform 36 和 Build Tools 36，设置 `JAVA_HOME` 与 `ANDROID_SDK_ROOT` 后运行：

```bash
npm ci
npm run android:apk
```

安装包输出为 `artifacts/yejian-0.4.0-android-debug.apk`，是可直接安装的测试版。可复制到手机安装，或连接手机后执行 `adb install -r artifacts/yejian-0.4.0-android-debug.apk`。此包使用本机 Android 调试签名；应用商店发布需另行配置正式签名，密钥不进入 Git。

连接并授权 USB 调试后，可以一条命令构建、复制 APK 并覆盖安装，保留应用数据：

```bash
pnpm install:android
```

只有一个可用手机或模拟器时自动选择；多个设备时用 `pnpm install:android --device <设备序列号>`，也可通过 `ANDROID_SERIAL` 指定。脚本先检查设备，再开始构建，任一步失败即停止。查看帮助用 `pnpm install:android --help`；只生成安装包用 `pnpm android:apk`。也保留 `npm run install:android` 用法，npm 传参时需加 `--`。

只更新客户端资源可执行 `npm run build:android`，打开原生工程用 `npm run android:open`。Web 构建仍输出到 `dist/`，Android 单独输出到 `dist-android/`。修改客户端后需要重新构建并安装 APK；部署网站不会替换已安装包内的界面。实现与验证方式见 [Android 客户端](docs/android.md)。

0.2.1 统一替换页间图标：白天使用浅底青色书页，夜间和星空使用青底白色书页，覆盖登录、侧栏、加载页、网页图标和桌面安装入口。Android 桌面图标及启动画面提供系统深浅色资源，桌面图标的缓存刷新由系统控制。原稿、生成方式和平台适配见[应用图标](docs/branding.md)。

0.2.2 修复深色主题下启动画面结束时的亮闪：原生窗口和 WebView 从首帧就采用保存的主题背景，跟随系统时按本次系统深浅色选择。

0.2.3 修复初始化、键盘弹出时的上下抖动，以及页面覆盖系统状态栏的问题：主题更新复用窗口背景，保留系统栏与键盘边距；窗口尺寸变化不再重复设置主题。

0.2.4 将系统栏背景与图标明暗一起更新，修复应用主题和手机主题不一致时状态栏文字不清晰的问题，并在横竖屏和系统主题变化后保持同步。

0.3.0 增加版本与更新入口、Android 系统分享导入、PDF 双指缩放和按文件记忆比例，以及整库 ZIP 备份与恢复。恢复会创建新目录，保留当前资料；备份包含附件、版本、青藜对话和翻译记录。设置中的更新服务需要部署配套 Worker，安装包通过已登录的私有接口下载。

## 本地运行

需要 Node.js 22.12 或更新版本。

```bash
npm ci
npm run dev
```

启动脚本会生成本地 `.dev.vars` 随机密钥、执行本地数据库迁移，并打印专属设置链接。用该链接打开 `http://127.0.0.1:5173`，设置并确认至少 8 个字符的密码即可使用。令牌位于 URL 的 `#setup=…` 片段中，进入页面后立即从地址栏移除，不放进请求查询参数。

前端默认端口为 `5173`，本地 Worker 默认端口为 `8787`；端口占用时自动顺延，实际入口以启动日志中的链接为准。可通过 `NOTE_UI_PORT` 和 `NOTE_WORKER_PORT` 指定起始端口。本地 D1 和 R2 保存在 `.wrangler/state`，与 Cloudflare 远端数据独立。`.dev.vars`、本地数据库、上传文件和测试产物均已加入 Git 忽略列表。不要删除 `.wrangler/state` 来重置密码。

本地开发不会自动触发 Cron，可在设置中执行一批清理，或访问 Wrangler 打印的本地定时任务测试地址。

## Cloudflare 部署

架构为 **Workers 静态资源 + Worker API + D1 + 私有 R2**。浏览器与 API 同源。正文保存在 R2 的不可变对象中，D1 保存节点、版本指针、文件引用、会话、阅读记录和容量登记。

已于 2026-10-01 部署到 [页间](https://note.xvi.app)。生产环境使用 `xvi-note` Worker、同名 D1 和私有 `xvi-note-files` R2 桶；配置位于 `wrangler.jsonc` 的 `env.production`，绑定 `note.xvi.app`，关闭 `workers.dev` 与预览地址。顶层数据库 ID 继续用于本地开发，保留原有 `.wrangler/state` 数据。线上是独立的新库，首次密码由使用者设置。

后续更新：

```bash
pnpm run deploy
```

这里的 `run` 不能省略：[`pnpm deploy` 是 pnpm 内置的工作区打包命令](https://pnpm.io/10.x/cli/deploy)，不执行本站的部署脚本。也可以继续使用 `npm run deploy`。

此命令在构建或数据库迁移失败时停止，不会继续发布。部署保留既有云端 Secrets。当前部署的专属首次设置链接保存在本机 `.wrangler/deploy/setup-link.txt`，不进入 Git；初始化后该链接不能再次设置密码。

迁移到其他 Cloudflare 账号时：

1. 在有部署权限的终端登录并创建资源：

   ```bash
   npx wrangler login
   npx wrangler d1 create xvi-note
   npx wrangler r2 bucket create xvi-note-files
   ```

   更新 `wrangler.jsonc` 中 `env.production.account_id`、`env.production.d1_databases[0].database_id` 及相应资源名称。保留顶层本地开发配置。R2 保持私有，不启用公开访问或公开自定义域名。

2. 分别生成两个独立随机值，作为 `APP_SECRET` 和 `SETUP_TOKEN`，通过 Wrangler Secret 输入。每个值至少 32 个字符，建议使用下面的 32 随机字节生成方式；不要把值写入 `wrangler.jsonc` 或 Git。

   ```bash
   node -e "process.stdout.write(require('node:crypto').randomBytes(32).toString('base64url') + '\n')"
   npx wrangler secret put APP_SECRET --env production
   # 再生成一个不同的随机值，用于下面的 SETUP_TOKEN
   npx wrangler secret put SETUP_TOKEN --env production
   ```

3. 运行 `pnpm run deploy`，打开 `https://你的站点/#setup=刚设置的SETUP_TOKEN`，由自己设置密码。初始化原子提交，完成后此链接无法再次设置密码。首次部署也支持 `pnpm run deploy --secrets-file 私有JSON文件路径`，JSON 包含上述两个密钥；仅将其作为首次配置使用，后续更新直接运行 `pnpm run deploy`。

4. 在 Cloudflare 控制台检查 Cron、请求日志、CPU 和 R2/D1 用量。可以在 `env.production.vars.APP_NAME` 修改站点名称。部署端重置命令的 `--remote` 已固定使用生产环境。

密码在浏览器使用独立随机盐与 PBKDF2 SHA-256 计算 600,000 次，服务端再使用 `APP_SECRET` 做 HMAC-SHA-256 校验，D1 只保存经 HMAC 处理的校验值和公开参数。原密码及可登录的派生值不落库、不记录日志；HTTPS 和限速仍生效。该方式避开 Cloudflare 云端 PBKDF2 100,000 次上限，保留原有密码计算强度；参考 [Libsodium 的客户端预计算方案](https://doc.libsodium.org/password_hashing#server-relief) 与 [OWASP Pepper 建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#post-hashing-peppers)。旧本地密码首次成功登录后自动升级，密码和资料保留；旧格式记录若迁入云端，应先执行部署端密码重置。轮换 `APP_SECRET` 后也需要重置登录密码并重新保存 AI Key。

### 免费额度验证状态

2026-10-01 的独立云端测试已通过设置密码、登录、修改密码、会话撤销、正文读写、上传、PDF Range、回收和清理；部署没有执行套餐升级。采集到的密码设置 / 登录 / 改密 CPU 最大值分别为 9 / 5 / 8 ms。接近 1 MiB 正文的读写达到 20 ms，永久删除达到 13 ms：这些请求此次成功，但超过免费版标称 10 ms CPU，**不能保证所有操作始终落在免费预算内**。完整记录见 [Cloudflare 部署验证](docs/cloudflare-deployment.md)。

后续容量与压力验收应在单独测试站点进行，每项至少重复 10 次并记录最大值与 P95；用 Workers Observability 的事件 CPU 时间核对，不以浏览器请求耗时代替。此次是功能冒烟验证，部分操作只执行一次，未覆盖 50 MB 文件上传或长期高负载。出现 CPU 限制时，应重新评审实现方式或部署预算，不能降低密码参数或自动升级套餐来掩盖问题。

截至设计核对日（2026-10-01），Workers Free 为每天 100,000 次请求、单次请求 10 ms CPU；D1 免费版每天读取 500 万行、写入 10 万行，单库上限 500 MB；R2 标准存储包含 10 GB-month、每月 100 万次 A 类和 1,000 万次 B 类操作。额度由账号中的项目共享，应用的 8 GB 上限不是费用封顶。R2 需要先开通订阅；请在部署时核对官方最新额度。

官方来源：[Workers 限制](https://developers.cloudflare.com/workers/platform/limits/)、[D1 计费](https://developers.cloudflare.com/d1/platform/pricing/)、[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)、[R2 计费](https://developers.cloudflare.com/r2/pricing/)、[R2 开通](https://developers.cloudflare.com/r2/get-started/)。

## 忘记密码

本地：

```bash
npm run reset-password -- --local
```

远端（需要 Cloudflare 部署权限）：

```bash
npm run reset-password -- --remote --url https://你的站点
```

命令先锁定登录和初始化入口、撤销所有会话，然后轮换初始化令牌，最后开放一次密码设置并打印新链接。中途失败保持锁定，可修复错误后重新运行。本地重置后需重启开发服务以读取新令牌。笔记、附件、回收站与历史版本均保留。

资料通过登录控制访问，没有使用登录密码进行端到端加密，因此密码重置不改变文件。请妥善保管 Cloudflare 部署权限。

## 项目结构

| 路径                    | 职责                                      |
| ----------------------- | ----------------------------------------- |
| `src/`                  | React 阅读界面、懒加载编辑器与 PDF 查看器 |
| `worker/auth.ts`        | 密码、会话、来源约束配合的编辑确认令牌    |
| `worker/library.ts`     | 笔记树、正文保存、版本与稳定链接          |
| `worker/arxiv.ts`       | arXiv 正文提取、版本确认与私有图片导入    |
| `worker/storage.ts`     | 私有文件、Range 读取、原子容量预留        |
| `worker/recovery.ts`    | 子树回收、恢复、分批清理                  |
| `worker/reading.ts`     | 收藏、最近访问、进度版本检查              |
| `worker/assistant.ts`   | 文件会话、流式生成、历史与 Markdown 导出  |
| `worker/translation.ts` | 划词翻译、持久缓存、原文位置与记录管理    |
| `worker/deepseek.ts`    | AI 凭据加密、连接测试与 DeepSeek 适配     |
| `migrations/`           | D1 schema、索引与事务保护触发器           |
| `scripts/`              | 开发环境、密码重置和测试服务              |

数据库提交使用 D1 batch 与触发器保证版本、引用及容量检查原子性。R2 与 D1 之间没有跨服务事务：上传先预留容量，提交失败保留旧版本并清理新对象；垃圾清理先在 D1 中标记对象并禁止新引用，R2 确认删除后才释放容量。定时任务每 30 分钟执行一批，未引用的草稿文件最多保留 24 小时。
